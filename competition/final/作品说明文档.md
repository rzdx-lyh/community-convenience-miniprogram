## 1. 项目说明

### 1.1 项目定位

邻里百事通小助手是一个面向社区居民的 AI Native 微信小程序，聚焦社区公共服务、报修、办事、地图导航和适老化体验。项目以微信小程序和微信云开发为基础，将大模型、Agent 工作流、RAG 知识检索、多模态识图和安全护栏融入实际业务流程。

### 1.2 目标用户

- 社区居民，尤其是老年人和行动不便人群
- 物业工作人员
- 社区管理员
- 维修人员

### 1.3 核心流程

```text
居民提问/上传报修照片
→ Agent 识别意图并规划任务
→ 调用社区知识库、地图、电话簿、通知、工单工具
→ 生成带来源的回答和下一步操作
→ 居民确认后进入报修/地图/电话簿
```

## 2. 小程序与 AI 能力说明

### 微信小程序能力

- 微信登录与用户身份
- 微信云开发与云函数
- 原生地图与 wx.openLocation
- 主动定位与授权失败回退
- 图片选择与云存储上传
- 分享与订阅消息能力
- 关怀模式与大字适配

### AI 能力

- **大模型**：云函数接入 DeepSeek，Key 只配置在云环境变量
- **Agent 工作流**：意图识别、任务规划、工具调用、下一步操作
- **RAG**：社区知识库、通知、电话簿、地图点位和工单数据检索
- **多模态**：报修照片识别故障类别、紧急程度和安全提示
- **AI 安全**：医疗、法律、紧急问题固定安全话术；无 Key/超时降级；号码幻觉校验
- **来源引用**：回答显示知识库、通知、地图或电话簿来源

## 3. 创新点说明

### AI 应用创新

AI 不只是聊天，而是直接参与社区办事流程，输出可执行操作。

### 场景创新

聚焦社区公共服务、适老化与三端协同，解决居民“不知道找谁、不会填表、不清楚位置”的问题。

### 产品创新

居民、管理端、维修端三端分离，AI 管家贯穿报修、地图、通知和电话簿。

### 技术创新

采用“规则规划 + 工具调用 + RAG + 大模型生成 + 安全护栏”的可控 Agent 架构。

### 商业模式创新

可扩展为社区物业 SaaS、社区服务运营和本地生活服务入口。

### 用户体验创新

提供流式思考状态、工具调用可视化、来源引用、关怀模式和失败兜底。

## 4. 技术实现

### 架构

```text
微信小程序
  ├─ 居民端 / 管理端 / 维修端
  ├─ AI 助手页面
  ├─ 地图、报修、通知、电话簿
  └─ 关怀模式
  
微信云函数
  ├─ auth：三端账号与会话
  ├─ qa：Agent / RAG / 安全护栏
  ├─ workorder：报修与识图
  ├─ notice / phonebook / service / circle / user
  └─ shared：AI、知识库、安全、工具与数据适配
```

### 关键实现

- Agent 规则规划器输出 intent 和工具列表
- RAG 使用知识库检索、来源收集和输出护栏
- 多模态使用 OpenAI 兼容视觉接口，密钥只在云函数
- 云函数根目录平铺共享模块，兼容微信云部署
- 自动化测试覆盖 Agent、识图、安全、版本和核心页面
