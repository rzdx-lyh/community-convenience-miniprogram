## 当前项目结论

当前工程是微信原生小程序，不是赛事要求中的 Web 应用。现有 AI 是知识库问答 + 可选大模型兜底，缺少 Agent 工作流、完整 RAG、多模态、Function Calling / MCP 和流式生成式 UI。

**要满足该赛道要求，必须新增一个独立的 AI Native Web 版本，不能直接把现有小程序作为参赛作品提交。**
