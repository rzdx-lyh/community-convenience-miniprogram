## 当前项目判断

当前“邻里百事通小助手”已经是微信小程序，形态符合赛道要求；社区便民、三端账号、地图、报修和关怀模式具备较好的技术实现、场景落地与体验基础。

当前主要短板是：

- AI 仍偏知识库问答，Agent 工作流不完整
- RAG 缺少向量检索与稳定的来源引用
- 多模态图片/语音能力尚未接入
- AI 能力还未贯穿报修、地图、服务预约等核心流程
- 缺少用户增长、运营闭环和赛事材料证据

下一阶段不需要改成 Web，而是在当前小程序上补齐 AI Native 能力并整理赛事材料。
