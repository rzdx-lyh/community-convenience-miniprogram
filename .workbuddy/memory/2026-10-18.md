**关键设计决策**
- **AI 从"答"变"办"**：一句话 → 识别意图 → 抽取参数 → 只补一项 → 草稿卡确认 → 回执 → 进度时间轴。写操作必须二次确认，断网时写操作禁用。
- **新 IA 5 Tab**：首页 / 办事 / **AI 管家（中心）** / 圈子 / 我的；Agent 不做浮球（触控与适老化考虑）。
- **Token 新增紫蓝 AI 色系**（`--ai:#5B54D6` / `--ai-light:#EEECFD` / `--ai-grad`），与品牌绿分工：绿=办事，紫=AI。紫配白 6.1:1、深字配浅紫 6.5:1，均过 AA。
- **功能分级**：F1 一句话办事、F2 步骤可视化、F3 主动提醒、F5 八分类、F7 进度时间轴、F11 长者专区 = 纯前端可落；F4 一件事、F6 预约取号、F9 政策计算器、F10 材料预检 = 需配置/后端增量；F8 电子证照、F12 缴费 = **仅演示**（证照需实名授权、缴费无资质，答辩不可宣称已对接）。
