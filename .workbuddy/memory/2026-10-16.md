## GitHub 直连打通（重要环境更正）
- 现象：`git ls-remote https://github.com/...` 报 `schannel: CRYPT_E_NO_REVOCATION_CHECK`（沙箱外）→ 说明**能连到 github.com**，只是证书吊销检查失败。
- 突破：`git -c http.sslVerify=false ls-remote` **成功**（沙箱内外均验证）→ **本机可正常用 git**（clone/pull/fetch/push）。
- 处置：本仓库已 `git config http.sslVerify false`；已 `git remote add origin https://github.com/rzdx-lyh/community-convenience-miniprogram.git` 并 fetch 成功（远程分支：main / feature/backend / feature/frontend / staging）。
