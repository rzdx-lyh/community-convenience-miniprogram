## 2. 待补齐项（按优先级排序）

### 🔴 P0-1 · ICP 备案（最长耗时，**建议立刻启动**）
- **为什么**：2023-09 起，未完成 ICP 备案的小程序**无法正式发布/上架**。
- **后台路径**：mp.weixin.qq.com → **设置 → 基本设置 → 小程序备案** → 填写主体/负责人信息 → 提交 → 平台初审 → 通管局审核。
- **你需准备**：主体证件（个人身份证 / 企业执照）、负责人信息、手机号、邮箱、小程序服务内容描述。
- **耗时**：通常 **1~20 工作日**（不可控）。
- **边界**：运维**不代做**（涉及账号、实名、证件）——只给路径与清单。

### 🔴 P0-2 · 切真云 / 关闭 mock（决定"数据真假"）
- **现状**：`miniprogram/config/env.ts` → `USE_MOCK=true`；9 个云函数目录**未部署**；KEY 未配。
- **正式发布必须完成看板 CR-018「六层真机联调」**（现状：仅第 1 层自测覆盖）：
  1. 部署云函数：`auth / circle / notice / phonebook / qa / service / user / workorder`（+ `shared` 打包进各函数）
  2. 配环境变量：`DEEPSEEK_API_KEY`（★AI）、`PHONE_AES_KEY`（★手机号加密）、`SUBSCRIBE_TEMPLATE_WORKORDER_DONE`（可选）；**不要**设 `CCF_FORCE_MOCK`/`CCF_MOCK_NO_SEED`（那是测试开关）
  3. 建集合 + `users.accountId` 唯一索引 + 导入 seed（`scripts/seed-data.json`）
  4. `getWXContext` 身份打通
  5. `msgSecCheck` 内容安全生效
  6. 大模型真调（8s 超时 + 降级阈值）
  7. **全链路冒烟必含 CR-012**：问「胸痛怎么办」→ 界面出现 **120**
  8. 冒烟全绿后才允许置 `USE_MOCK=false`
- **我可协助**：云函数部署命令、环境变量清单、集合/索引/seed 脚本核对（需你的云环境操作权限）。

### 🟠 P1-1 · 《用户隐私保护指引》
- **代码实测采集项（结论）**：
  | 采集项 | 是否采集 | 证据 |

  | **麦克风** | ❌ **否** | `pages/assistant/index.ts:248`「语音输入未开通，请直接输入文字」 |
