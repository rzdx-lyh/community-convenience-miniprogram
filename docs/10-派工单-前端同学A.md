## 五、五条硬纪律

1. **全站唯一请求出口** `utils/request.ts` —— 页面里**禁止**出现 `wx.cloud.callFunction`。
2. **mock 双通道**：`config/env.ts` 的 `USE_MOCK` 一个开关切换 mock/真实云函数；联调时置 `false`，**零代码改动**。
3. **接口名一字不差**：`workorder:list`，不是 `workorder.list`（半角冒号）。
4. **运行时一律相对路径**：`@/` 别名真机会白屏（DevTools 的 TS 插件不解析 tsconfig paths）。
5. **不推 main、不改契约**：契约有疑问报给主分支负责人（owner）裁决，绝不私改字段。

**推荐技术约定**：缩进 2 空格 / 单引号 + 分号（`.prettierrc`）；TS strict 全开；提交信息 `feat(FE-x): 内容`；每次提交前跑 `npm run verify`（typecheck + lint + test）。
