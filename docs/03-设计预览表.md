## 1. 首页信息架构（自上而下）

| # | 区域 | 高度（rpx） | 核心内容 | 说明 |
| --- | --- | --- | --- | --- |
| 0 | 状态栏 | 系统 88 | — | 自定义导航，`navigationStyle: custom` |
| 1 | 导航区（定位） | 88 | 左侧「📍 当前位置」chip；右侧留空避开微信胶囊 | 胶囊占位右侧 ≥190rpx 禁放内容 |
| 2 | 用户信息条 | 152 | 头像 96 + 昵称 34加粗 + 社区账号 24；最右「紧急求助」按钮 | 昵称区最大宽 374rpx，超长省略 |

**交互状态（五态，缺一不可）**
- **默认 ✔**：如上。
- **空 ✔**：紧急公告无数据 → 区底改 `--bg` 描边样式，文案「暂无紧急通知，社区运行正常 👍」+「查看本周公告」按钮；用户信息条未登录 → 头像用灰底默认图 + 昵称「点击登录」。
- **加载 ✔**：定位 chip 显示「定位中…」；用户信息条头像灰块骨架；紧急公告区 2 行灰条骨架呼吸 1.5s；宫格 4 格灰块骨架。
- **错误 ✔**：紧急公告区加载失败 → 区内提示「⚠️ 公告加载失败」+「重试」（中档按钮）；宫格静态不依赖接口，不设错误态。
- **断网 ✔**：导航区下方通栏提示条（高 64rpx、底 #FBF0E0、字 24rpx #D98E32）「网络不可用，内容可能不是最新」；紧急求助按钮**保持可用**（拨号走系统能力）。

**交互行为**
| 元素 | 行为 |
| --- | --- |
| 定位 chip | 点击 → `wx.getLocation` 重新定位；拒绝授权 → chip 文案「点击开启定位」+ 引导 |
| 头像/昵称 | 未登录 → 触发静默登录后仍可点 → 跳「我的」 |
| 紧急求助 | 点击 → 半屏底部弹层（紧急求助面板：110/119/120 + 物业值班 + 一键拨号），见 §4.2 |
| 紧急事项行 | 点击 → 通知详情（type=urgent）；每 3s 自动轮播下一条 |
| 本周公告 / 最近路况 | 本周公告 → 通知列表（筛选通知）；最近路况 → 社区圈子（路况 Tag）或通知详情（待产品定，见 §7 待裁决） |
| 宫格 4 格 | 分别跳：报修创建 / 电话簿 / AI 助手 / 生活服务承接页（见 §7 待裁决） |

**关怀模式三条硬规则（验收点）**
1. **字号重排**：所有字号按 `page.care-mode` 变量放大 ≈1.25×（正文 32→40rpx），行高 1.4→1.5；不做整页 `transform: scale`。
2. **布局重排**：宫格 2×2 → **1 列 4 行**（每格 686×176rpx）；用户信息条高度 152→200rpx；紧急公告区行高与 pill 同步加大。
3. **对比度升级**：禁用 `--text-3` 作正文（升 `--text-2` 起）；紧急区文字保持 `--text-1`；描边类元素加粗 2→3rpx。
4. 附带：首页顶部提供关怀模式开关（本次改版并入用户信息条右侧长按/或「我的」页开关，见 §7 待裁决）。
