## 二、仍需准备的东西（重点）

### 1. 演示载体：体验版（已就绪）
- 用**你自己的手机**装体验版；若二维码过期（标注 10-21 前有效），后台**重新生成体验版二维码**即可（不用改代码）。
- 备选：开发者工具**真机预览**（需电脑在线）。

### 2. 投屏方式（选一种）
- **手机 → 投影/大屏**：系统自带投屏 / 微信投屏 / 采集卡；
- 或 **直接录屏**（现场用录屏文件播放，最稳，不怕现场网络）。
- 建议**双保险**：现场投屏 + 本地录屏备份。

### 3. 演示脚本（按分镜走，3~4 分钟）
| 时段 | 内容 | 要点 |
|---|---|---|
| 0:00-0:30 | 开场：首页特写 | 一句话点题：社区便民 + AI + 适老化 |
| 0:30-1:10 | 报修主流程 | 创建→拍照→AI 摘要→提交→列表状态 |
| 1:10-1:50 | AI 问答 | 提问→回答→免责声明→兜底拨号 |
| 1:50-2:20 | 电话簿 + 通知 | 分类搜索 + 一键拨号 + 通知列表 |
| 2:20-2:50 | 适老化 | 切换关怀模式 → 大字/语音对比 |
| 2:50-3:30 | 收尾 | 我的页 + 隐私政策 + 总结 |

### 4. 断网降级备份
- 另录 **1 分钟"断网降级"片段**（AI 不可用 → 兜底话术 + 电话）作备片。

### 5. 演示视频（提交材料必需，3 分钟以上）
- 1080p，竖屏手机直拍，画音同步，**AI 环节真机实拍**。

### 6. 彩排
- 完整走一遍**核心三流程**（报修 / AI 问答 / 电话簿）+ 关怀模式，计时。
