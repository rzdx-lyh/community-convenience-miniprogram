# 29 · DeepSeek 密钥配置与 AI 通道验收

> 用途：把 AI 从「本地知识库兜底」升级成「**真大模型回答**」。
> 这是大赛 **S2 硬指标**（AI 助手真实调用大模型 API）+ **20% 评分项（AI 融合）**。
> 配置只需 3 步，但**有一个前置条件必须先满足**，否则配了也没用。

---

## 0. 前置条件（最重要，先看）

云函数**超时目前是 3 秒**，而一次大模型请求常要 3–8 秒。

> 函数会在模型返回前被掐断 → 表现为「**配了 Key 但 AI 还是降级**」。

**所以顺序是**：

```
① 把 qa / workorder 的超时改成 20s   ← 见 docs/26
② 再配 DEEPSEEK_API_KEY              ← 本文
③ 真机验收
```

代码侧我已经加了对这条的显式警告（日志会打印 `degraded: timeout ... 检查云函数超时是否 > 8000ms`）。

## 1. 拿 Key（约 2 分钟）

1. 打开 <https://platform.deepseek.com/> → 注册 / 登录
2. 左侧 **API Keys** → **创建 API Key**
3. 复制那串 `sk-xxxxxx`（**只显示一次**，先存到记事本）
4. 充点值（新账号一般有赠额；日常演示用量极小，10 元够用很久）

⚠️ **Key 只给过程序，不要**发到群里、不要写进代码、不要提交到 git（本项目 `.gitignore` 已覆盖常见位置）。

---

## 2. 配到云函数环境变量（3 步）

### 方法 A：微信开发者工具（推荐）

1. 打开开发者工具 → **云开发**
2. 左侧 **云函数** → 点 **`qa`**
3. 上方 **配置** → **环境变量** → **新增环境变量**
   - 名称：`DEEPSEEK_API_KEY`
   - 值：`sk-xxxxxx`（你刚复制的那串）
4. **保存**
5. **同样给 `workorder` 也配一份**（工单 AI 摘要也要用；不配就走原文截断兜底，不报错）

### 方法 B：腾讯云开发控制台

1. <https://tcb.cloud.tencent.com/> → 环境 `cloud1-d5g1xuxxf9eb5b758`
2. 云函数 → `qa` → 函数配置 → 环境变量 → 新增
3. 同上填 `DEEPSEEK_API_KEY`

## 3. 验收（三步确认真的通了）

### 3.1 看日志（最准）

开发者工具 → **云开发 → 云函数 → qa → 日志**，问一句问题后看输出：

| 日志 | 含义 |
|---|---|
| `[ai] ok cost_ms=1234 http=200` | ✅ **真模型返回了** |
| `[ai] degraded: no_key` | ❌ Key 没配上（环境变量没保存，或配到别的函数了） |
| `[ai] degraded: timeout` | ❌ 云函数超时太小，**回去做第 0 步** |
| `[ai] degraded: http_401` | ❌ Key 无效/过期 |
| `[ai] degraded: http_402` | ❌ **余额不足**，去充值 |
| `[ai] degraded: http_429` | ❌ 触发限流，等一会儿 |
| `[ai] degraded: network` | ❌ 云函数出站网络异常 |

### 3.2 看回答形态

- **真模型**：回答是**重新组织过的句子**，带「AI 生成仅供参考」免责声明
- **知识库兜底（degraded）**：回答是**知识库原文照抄**，同样带免责声明

> 两者都带免责声明，所以**别看免责声明判断**，看句子是不是"重写过的"。

### 3.3 前端埋点

问完后 Console 里会有 `[cloud]` 开头的记录；降级时 `_aiReason` 字段会给出原因
（`no_key` / `timeout` / `http_401` / `kb_miss` / `guard` / `risk`）。

## 4. 当前代码的降级链（配不配 Key 都不会白屏）

```
用户输入
  ↓
高风险命中？（涉医/涉法/急救）→ 固定安全话术（不调用模型，省 token 且避免胡说）
  ↓
本地知识库命中？
  ├─ 否 → 兜底话术 + 便民电话
  └─ 是 → 调大模型
           ├─ 成功 → 输出护栏（号码必须能在知识库原文找到）
           │          ├─ 通过 → 真模型回答 ✅
           │          └─ 拦截 → 回落知识库原文（防幻觉）
           └─ 失败 → 回落知识库原文（仍有用）
```

**所以断网 / 没 Key / 模型挂了，演示都不会翻车**——这正是本地 45 条问答库存在的意义。

---

## 5. 常见问题

| 问题 | 答 |
|---|---|
| 配了 Key 需要重新部署云函数吗？ | **不需要**。环境变量在云端配置，改完即生效 |
| 改了 `shared/ai.js` 需要重新部署吗？ | **需要**（代码变了）。跑 `npm run build:cf -- --clean` 再部署 |
| Key 会泄露吗？ | 只在云函数环境变量里，源码零明文；`.gitignore` 已覆盖 `keys/` 与 `.env` |
| 一个 Key 够吗？ | 够。个人主体演示用量极小 |
| 能不能用别的模型？ | 代码里 `MODEL = 'deepseek-chat'` 写死；换模型要改 `cloudfunctions/shared/ai.js` |
