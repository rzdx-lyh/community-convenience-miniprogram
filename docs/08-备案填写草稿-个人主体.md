## 一、提交前先做 2 件事

### ① 改名（强烈建议，否则大概率驳回）⚠️
- 当前名称 **"风残烛火心碎"** 与"社区便民"不符 → 备案要求「名称与经营内容一致」，几乎必被驳回。
- 路径：`mp.weixin.qq.com → 设置 → 基本设置 → 小程序名称 → 修改`
- 个人主体小程序 **一年可改 2 次名称**，改完需通过名称审核。
- 建议名示例：**「<你所在社区/团队名>社区便民服务」**

### ② 认证：个人主体**不需要**微信认证（免 300 元）
- 个人主体走"去备案"时若提示需认证，按后台提示处理；一般**直接可备案**。

## 三、提交后（务必盯紧）
1. **平台初审** 1–2 工作日 → 保持电话畅通，资料问题会退回补正。
2. **工信部短信核验**：收到 **12381** 短信 → **24 小时内**登录 `https://beian.miit.gov.cn/` 完成核验。**超时 = 驳回重来**。
3. **通管局审核** 1–20 工作日 → 可能电话回访（问"小程序做什么"，如实回答）。
4. 通过 → 下发备案号（如"粤ICP备XXXXXXXX号"）→ 后台显示"已备案"。

## 四、高频驳回原因（个人主体）
| 原因 | 规避 |
|---|---|
| **名称与内容不符** ⚠️ | 先改名再备案 |
| 通讯地址与证件不一致 | 逐字对照身份证填写 |
| 证件照模糊 / 超 200KB | 重拍，压到 100–200KB |
| 短信核验超时 | 收到即核 |
| 类目选了不符合个人性质的项 | 选「工具」 |
