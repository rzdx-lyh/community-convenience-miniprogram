## 3. 各版本要点

### v0.0.1（2026-10-10 起，10-16 打 tag）
- 从零搭建：小程序目录、Design Token、mock 数据层、8 个云函数骨架、TS/ESLint/Vitest 配置。
- 目标赛事确定：讯方杯「公共服务 → 社区便民」。

### v1.0.1（2026-10-18）
- 9 个页面、8 云函数、19 业务动作、8 集合的代码基线。
- 版本归一：源码注释 / package / 8 个云函数包 / README 四处版本号统一，`tests/version.test.ts` 守护。
- 体验版 v1.0.0（10-14）已可扫码演示，但定位/云身份尚未打通。

### v1.0.2-legacy（2026-10-19）
- 清新绿 UI 的最终基线存档（随后 CR-023 改为政务蓝 `#1F5FD6`），用于回滚对照。

### v1.1.0（2026-10-19）
- 服务分类页落地（4 类 / 8 板块 / 38 项），统一预约收口。
- 页面级 AI 入口 + 办事大厅 8 场景集群 + 45 条本地问答库。
- 83 枚 SVG 矢量图标体系、TabBar 图标；6 个新服务页（配餐/指南/账单/健康档案/共享设备/快递代取）。
- 修复云函数 `MODULE_NOT_FOUND`（38 处 `../shared` → `./shared`）。

### v1.2.0（2026-10-23）
- 首启资料设置页（头像/昵称/定位/协议），路由守卫。
- 文化便民活动页（义诊/邻里活动/长者手机课），服务分类按 tag 过滤。
- 云函数部署定型：共享模块**平铺进函数根目录** + `--remote-npm-install`（解决全站 401）。
- 8 函数超时改 20s；`USE_MOCK=false` 切真云；体验版上传成功（1.33 MB）。

### v1.2.1（2026-10-26，最新）
- 微信接口审核：`wx.getLocation` 场景未通过 → 彻底移除定位接口调用；
- 新增 `miniprogram/config/community.ts`（社区中心 + 6 个位置点），首启/首页/地图三处改为手动选择；
- `app.json` 删除 `requiredPrivateInfos` / `scope.userLocation`，地图移除 `show-location`；
- 名称统一为备案名「邻里百事通小助手」；新增 `docs/37` 说明与 11 条守卫测试；
- 质量：`npm run verify` 351/27 全绿、34 页自检通过、`cli preview` 通过、体验版上传成功。
