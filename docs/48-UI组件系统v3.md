# 暖纸社区 UI Kit v3

版本：v1.3.1

## 目标

把页面级零散样式收敛为可复用的全局 UI Kit，统一三端的基础组件、交互状态和视觉节奏。

## 新增样式层

`miniprogram/styles/ui-kit.wxss` 已在 `app.wxss` 顶部导入，覆盖：

- 自定义导航栏与彩色页头
- 卡片、分组卡、列表
- 主按钮、次按钮、危险按钮、禁用态
- 胶囊筛选、标签、状态角标
- 输入框、搜索框、表单容器
- 底部弹层和遮罩
- 空态、加载态和错误态基础样式
- 页面进入动效
- 关怀模式下的尺寸和布局适配

## 设计 Token 扩展

新增 `--surface-2`、`--line-strong`、`--shadow-soft`。

现有深青蓝、陶土橙、暖纸底、暖白卡、功能色继续作为唯一主题来源。

## 组件统一

- 导航高度、返回按钮、右侧操作统一。
- 页头增加圆角、阴影和装饰层次。
- 卡片统一边框、圆角、阴影和暖白背景。
- 主按钮统一渐变、高度、字重和阴影。
- 筛选胶囊统一选中和未选中状态。
- 表单统一边框、焦点环和背景。
- 弹层统一圆角、阴影和安全区。
- 所有页面内容支持统一进入动效。

## 测试

- 新增 `tests/ui-kit.test.ts`
- 覆盖全局导入、核心组件选择器、动效、关怀模式选择器和旧色板禁用
- 全量验证：42 个测试文件、417 条测试通过
