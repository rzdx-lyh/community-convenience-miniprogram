# 云函数身份 401 排查与修复（2026-10-21）

## 结论

本次 401 **不是**「云环境与 AppID 不匹配」，也**不是**「开发者工具未登录」，而是：

> Windows 版微信开发者工具上传本地 `node_modules` 后，云端函数无法 `require('wx-server-sdk')`。
> `cloud.js` 捕获异常后静默降级为内存 mock，导致 `getWXContext()` 根本没有被调用，最终所有需要身份的动作返回 401。

关键诊断结果：

```json
{
  "hasOpenid": false,
  "cloudReady": false,
  "dbIsMock": true,
  "identityEnvPresent": true,
  "cloudError": "require_wx_server_sdk: Cannot find module 'wx-server-sdk'"
}
```

其中 `identityEnvPresent=true` 且 `WX_OPENID` 等变量已由运行时注入，说明身份注入本身正常；`cloudReady=false`
说明 SDK 没加载成功。

## 已验证事实

- 开发者工具 CLI `islogin` 返回 `{"login":true}`。
- `cloud env list --appid wx6af52092db32a671` 返回 `cloud1-d5g1xuxxf9eb5b758`。
- 该环境的云函数列表包含 auth / circle / notice / phonebook / qa / service / user / workorder。
- 开发者工具模拟器 `wx.getAccountInfoSync()` 返回 AppID `wx6af52092db32a671`。
- 云函数运行时环境变量中存在 `WX_CONTEXT_KEYS`、`WX_OPENID`、`WX_APPID`、`TCB_ENV`。

因此可以排除跨 AppID、跨账号和游客登录问题。

## 正确部署方式

共享模块仍按现有方案平铺到函数根目录，不改成子目录。上传时必须使用远端依赖安装：

```powershell
& 'D:\app\微信\开发小程序\微信web开发者工具\cli.bat' cloud functions deploy `
  --env 'cloud1-d5g1xuxxf9eb5b758' `
  --paths 'C:\Users\Administrator\Desktop\code\ai web\社区便民小程序\cloudfunctions\auth' `
  --remote-npm-install `
  --project 'C:\Users\Administrator\Desktop\code\ai web\社区便民小程序' `
  --lang zh
```

8 个函数逐个执行，或把 `--paths` 后的单个目录替换为对应函数目录。**不要省略 `--remote-npm-install`**。

部署完成后，`auth:whoami` 应返回：

```json
{
  "cloudReady": true,
  "dbIsMock": false,
  "hasOpenid": true,
  "hasAppid": true,
  "env": "cloud1-d5g1xuxxf9eb5b758",
  "cloudError": ""
}
```

## 最小复现 / 验证命令

1. 确认工具登录态：

```powershell
& 'D:\app\微信\开发小程序\微信web开发者工具\cli.bat' islogin `
  --project 'C:\Users\Administrator\Desktop\code\ai web\社区便民小程序' --lang zh
```

2. 确认当前 AppID 的环境列表：

```powershell
& 'D:\app\微信\开发小程序\微信web开发者工具\cli.bat' cloud env list `
  --appid 'wx6af52092db32a671' --lang zh
```

3. 在开发者工具 Console 执行：

```js
wx.cloud.callFunction({ name: 'auth', data: { action: 'whoami' } })
  .then(r => console.log(JSON.stringify(r.result)))
```

判定：

- `identityEnvPresent=false`：运行时未注入身份，检查 AppID/环境归属与登录态。
- `identityEnvPresent=true` 且 `cloudReady=false`：`wx-server-sdk` 加载失败，使用 `--remote-npm-install` 重新部署。
- `cloudReady=true` 且 `hasOpenid=true`：身份链路正常。
- `forceMock=true`：删除云函数环境变量 `CCF_FORCE_MOCK`。

## 两种备选故障分支

### A. 环境确实不属于当前 AppID

1. 在微信开发者工具右上角确认当前登录账号与小程序管理员/开发者账号一致。
2. 打开「云开发」控制台，确认环境列表中存在目标环境。
3. 若不存在，在该 AppID 下创建新环境。
4. 修改 `miniprogram/config/env.ts` 的 `CLOUD_ENV_ID`。
5. 在新环境重建 8 个集合、索引，并重新导入 `scripts/seed-data.json`（或 `scripts/seed/import/*.json`）。
6. 在云函数环境变量中配置 `DEEPSEEK_API_KEY`、`PHONE_AES_KEY` 等；不要配置 `CCF_FORCE_MOCK` / `CCF_MOCK_NO_SEED`。
7. 使用 `--remote-npm-install` 重新部署 8 个函数。

### B. 开发者工具登录态异常

1. 退出开发者工具并重新扫码登录，不要使用游客模式。
2. 重新打开项目，确认 `cli islogin` 返回 `true`。
3. 清缓存并重新编译，再从 Console 调用 `auth:whoami`。

## 仍需手工完成的配置
