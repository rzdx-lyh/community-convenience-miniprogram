## 一、四个新组件

### 1. LocBar 实时定位（首页右上角，替换原 `📍 阳光社区 ›`）

| 项 | 规格 |
|---|---|
| 尺寸 | 高 26px，圆角 99px，内边距 0 8px，最大宽 172px |
| 字体 | 9.5px / 700，省略号截断 |
| 底色 | `rgba(255,255,255,.16)`，描边 `rgba(255,255,255,.32)` |
| 未授权态 | 底 `rgba(255,196,0,.24)`，描边 `rgba(255,214,102,.65)` |
| 定位中 | 7px 白点 + 1.4s 呼吸外环（`@keyframes lpr`） |

状态机：`locating` —(1.3s)→ `ok`；`denied` 走系统授权引导；`manual` 手选小区。

内容：状态点/图标 + 主文案（`阳光社区 · 3 号楼` / `定位中…` / `未授权 · 点此开启`）+ `›`。
点击 → 定位面板：示意缩略图、当前位置、定位方式（GPS + Wi-Fi 融合）、精度、重新定位、手选小区、隐私说明。

**小程序落地**：`wx.getLocation({type:'gcj02'})` → 逆地理 → 显示小区/楼栋；
用 `wx.getFuzzyLocation` 更合规（模糊定位，够用且不采集精确轨迹）；
`wx.onLocationChange` 仅在「地图页」开启，离开即 `offLocationChange`。

### 2. MapCard 地图卡（新增「社区地图」页）

| 项 | 规格 |
|---|---|
| 容器 | 高 238px，圆角 12px，必须有固定高度（否则 GL 不渲染） |
| 标记 | 26×34px，白色描边 2.4px，默认锚点 `{x:13,y:34}` |
| 我的位置 | 18×18px 红色标记 |
| 浮层 | 左上分类胶囊（全部/服务点/便民设备）、右上图例、右下 FAB 重新定位、左下比例尺兼底图切换 |

数据：5 个点位（物业、卫生站、共享雨伞、共享充电宝、生鲜自提），字段
`{id,n,d,ty,i,c,lat,lng,walk,open}`，按步行距离排序。

**合规（红线）**：
- 只用腾讯位置服务 GL JS（或高德/百度/天地图），**禁止** Google / Apple / Bing 海外 / Mapbox / Leaflet+OSM 瓦片。
- 前端**零密钥**：走 key 代理模式，`_TMapSecurityConfig` 在 SDK `<script>` 之前注入，SDK URL 不带 `?key=`。
- 坐标系统一 **GCJ-02**；不使用 `mapStyleId`（默认 key 不支持，会灰底）。
- 自定义图标用内联 `data:image/svg+xml`，不引用官方 demo 图片路径。
- **小程序落地**：原生 `<map>` 组件 + `markers` + `bindmarkertap`，`wx.openLocation` 做导航；需在微信后台配置、并展示审图号。

兜底：SDK 未到达 / 加载异常 / 用户主动切换 → 显示内置 SVG **示意底图**（`#tmapFb`），永不出现空白灰块。

### 3. AiBubble AI 回答（新增「AI 助手 / 智能问答」）

| 项 | 规格 |
|---|---|
| 气泡 | 最大宽 88%，圆角 12px（对话侧 4px），正文 12px / 1.68 |
| 用户气泡 | 底 `--blue`，白字，右对齐 |
| AI 气泡 | 白底 + 卡片阴影，左对齐 |
| 结构 | 模型标签 → 思考步骤 → 正文 → 来源 chips → 建议追问 |
| 思考步骤 | 左侧 2px 虚线，10px 灰字，完成打 `✓` 转深色 |
| 来源 chips | 8.5px，底 `#F1F5FD`，`📎 来源名` |
| 降级态 | 金色提示条 `免费模型通道暂时不可用，已用本地知识库作答` |

状态矩阵：`思考中` / `已答（带耗时 4.2s）` / `本地降级` / 建议追问。
模型切换：右上角 `⚡ 模型名 ▾` → 底部面板，3 个免费通道。

**关键设计**：思考步骤是**真的**——免费模型首字延迟 5-10s，用「理解问题 → 检索知识库 → 组织回答」三步把等待变成可理解的进度，而不是转圈。

## 二、免费模型接入（已实测可用）

### 原型阶段（浏览器直连，无 key）

| 能力 | 端点 | 实测 |
|---|---|---|
| 文本 | `POST https://text.pollinations.ai/openai`（OpenAI 兼容） | 200，中文正常，**9.4s**，`Access-Control-Allow-Origin: *` |
| 图像 | `GET https://image.pollinations.ai/prompt/{prompt}?width&height&nologo=true&seed=` | 200，直出 JPEG，**1.4s** |

注意：纯 GET `text.pollinations.ai/{q}` 传中文会超时（>20s），**必须走 POST `/openai`**。
文本超时阈值设 16s，失败/超时即降级本地知识库。

### 正式上线（小程序必须这样走）

小程序 `wx.request` 需要「合法域名」白名单，海外免费端点无法备案接入，因此：

```
小程序端  →  云函数 aiFree  →  免费模型 API
                ↑ 密钥只放云函数环境变量，源码零明文
```

可选免费/有免费额度的模型（按国内可用性排序）：

1. **智谱 GLM-4-Flash** —— 永久免费，中文好，适合问答；
2. **阿里百炼 Qwen-Flash / qwen-turbo** —— 有免费额度；
3. **硅基流动 SiliconFlow** —— `Qwen2.5-7B`、`FLUX.1-schnell`（图）有免费额度；
4. **智谱 CogView-3-Flash** —— 文生图免费；
5. **腾讯混元 lite** —— 与腾讯地图同生态，便于统一账号体系。

云函数返回结构建议：
```js
{ ok:true, model:'glm-4-flash', text:'...', cites:['服务指南 · 便民工具'], ms:4200 }
{ ok:false, reason:'timeout', fallback:'local' }   // 前端据此显示降级态
```

## 四、合规与隐私

- 定位：仅用于就近匹配与排序，**不保存轨迹、不对其他居民展示**，面板内明示；小程序端优先 `getFuzzyLocation`。
- 地图：GCJ-02；底图与审图号随腾讯位置服务；不标注军事/涉密点位。
- AI：回答标注来源；医疗类强制加「以上为健康提示，不替代医生诊断」；不编造社区电话与补贴金额。
- 文生图：不用于医疗、证件、人脸场景；图片仅存本机。
