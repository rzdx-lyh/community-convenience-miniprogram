## 第 4 步 · 提交备案（核心）

**入口**：`设置 → 基本设置 → 小程序备案 → 去备案`

按 `docs/08-备案填写草稿-个人主体.md` 逐字段填：

1. **主体信息**：姓名 / 身份证 / 证件照 / 所属地区 / 通讯地址 / 手机号 / 邮箱
2. **主体负责人**：默认复用主体信息
3. **小程序信息**：名称（第 1 步改好的）/ AppID 自动带入 / **服务内容=工具** / 服务内容描述（草稿里有模板）/ **前置审批=以上都不涉及**
4. **小程序负责人 + 人脸核身**：白色/浅色干净背景
5. **提交**

⏰ **提交后死盯这条**：
- 平台初审 **1~2 工作日**；
- 收到 **12381 短信 → 24 小时内**去 `https://beian.miit.gov.cn/` 核验（**超时=驳回重来**）；
- 通管局 **1~20 工作日**；期间保持电话畅通（可能电话回访）。
- 通过 → 下发备案号 → 后台显示"已备案"。

✅ 完成后：具备正式发布资格。
