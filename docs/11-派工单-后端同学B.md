统一响应恒为 `{code, msg, data}`；错误码只用 **0 / 400 / 401 / 403 / 404 / 429 / 500 / 503**，不发明新码。

| | `list` | `{status?, page?, pageSize?}` | `{list, total}` |
| | `detail` | `{id}` | `{workorder}` |
| | `cancel` | `{id}` | `{ok}` |
| | `handle` | `{id, action: assign\|process\|done, note?}` | `{workorder}` |

分页：`page` 从 1 起，`pageSize` 默认 10 上限 50，返回 `{list, total}`，`total` 为过滤后总数。

## 六、六条硬纪律

1. **统一响应** 恒为 `{code, msg, data}`，**无裸返回**。
2. **鉴权**取 `wxContext.OPENID`（不可伪造）；写操作走 `requireStaff` 校验 `users.role`；居民越权访问他人工单返回 403。
3. **时间一律** `new Date().toISOString()`（ISO8601），**禁止时间戳数字**。
4. **状态机**：`pending→assigned→processing→done`；非法流转返回 400。
5. **AI**：超时 **8s、失败不重试、直接降级**；日志含 `cost_ms`。
6. **密钥只走环境变量**（`DEEPSEEK_API_KEY` / `TCB_ENV` / `PHONE_AES_KEY` / `SUBSCRIBE_TEMPLATE_WORKORDER_DONE`），**永不进代码、永不进 git**。

**隐私**：手机号 AES-256-GCM 加密入库，出参一律脱敏 `138****1234`。
