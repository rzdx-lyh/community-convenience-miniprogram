## 一、项目概述

面向社区居民的公益性便民服务微信小程序，聚焦「**通知公告 + 报修工单 + 便民电话 + AI 办事问答**」四大场景，并做**适老化（关怀模式）**。

核心特点：
- **原生微信小程序 + TypeScript**，自定义导航，4 Tab（首页 / 服务订单 / 社区圈子 / 我的）
- **微信云开发（CloudBase）** 后端：8 个云函数、8 个数据库集合、1 个内置知识库 JSON
- **AI 能力**：DeepSeek 大模型 + 本地知识库检索（RAG）+ **双层安全护栏**（涉医/涉法/紧急求助固定话术）+ 降级链路
- **双通道数据**：`USE_MOCK` 开关切换「本地 mock 演示」与「真实云函数」
- 工程化：vitest 单测、tsc 类型检查、eslint、后端自测脚本

## 五、小程序前端

- **页面**：9 个（路由见 `app.json`；Tab 4 项：首页 / 服务订单 / 社区圈子 / 我的）
- **自定义导航**：顶部「胶囊占位行」+ 定位行（`当前社区`），避让微信胶囊/灵动岛
- **首页结构**：绿色渐变头部 → 白色通知卡（负边距叠压）→ 双 pill → 2×2 四类服务宫格
- **数据通道**：`config/env.ts` 的 `USE_MOCK` 是**全站唯一开关**（`true`=本地 mock，`false`=云函数）
- **接口调用**：统一走 `services/`，底层 `utils/request.ts` 按契约**形态 B**（`name='<资源>'` + `data.action='<动作>'`）
- **降级**：宫格数据失败回退本地常量 `config/service-grid.ts`，保证 0 白屏
- **适老化**：关怀模式（大字 + 语音播报），`store` 持久化 `elderMode`

## 七、接口契约

- **形态 B（唯一合法写法）**：
  ```js
  wx.cloud.callFunction({ name: '<资源>', data: { action: '<动作>', ...参数 } })
  ```
  > 云函数名**不含冒号**；`xxx:yyy` 只是文档里的逻辑名记法。
- **规模**：资源 **8** 个 / 动作 **19** 个 / 错误码 **8** 个
- **统一响应**：`{ code, msg, data }`；`code !== 0` 为失败
- **分页**：`page` 从 1 起，`pageSize` 默认 10 上限 50；时间为 ISO8601；图片走云存储 fileID
- **鉴权**：云函数自动取 `wxContext.OPENID`，写操作按 `users.role` 校验

**错误码**：`0` 成功 / `400` 参数错误 / `401` 未登录 / `403` 无权限 / `404` 不存在 / `429` 频繁 / `500` 内部错误 / `503` AI 不可用（已降级）。

## 八、AI 能力设计

- **选型（C3 判定）**：先判定"能否用工作流解决"，确需模型才调大模型（省成本、防幻觉）
- **RAG**：先检索本地知识库 `kb.json`；**未命中阈值以下不调用大模型**，直接降级
- **双层护栏**：
  1. **输入校验**：注入正则 + 高风险关键词（涉医 `medical` / 涉法 `legal` / 紧急 `emergency`）
  2. **输出引用校验**：电话/政策/金额必须存在于命中文档
- **高风险固定话术（CR-012）**：命中涉医/涉法/紧急 → **不调大模型**，返回契约内固定安全话术，`degraded=true`，附**真实应急号码**（如「胸痛」→ 出现 **120**）
- **降级路径**：AI 不可用时给**联系电话**兜底（物业/居委会/120 等），保证可演示
- **多轮会话**：`qa_sessions` 保留最近 3 轮、单条 ≤300 字、总量 ≤2000 tokens、2 小时过期
