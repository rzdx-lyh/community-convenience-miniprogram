### 3.4 类名与原型的三处「有意偏移」（必读，否则会踩坑）

1. **原型的 `.ic` 底座已改名 `.ib`**
   原型里 `.ic` 是「图标底座」（40×40 圆角 + flex 居中 + 淡色底），而 `icons.wxss` 的 `.ic` 是「图标本体」（background-image + 尺寸档）。
   两者同名同权重 → 后者被前者覆盖，所有图标会变成 80rpx 带圆角底座。
   生成器已把原型底座统一改名为 `.ib`。**页面写图标一律 `<view class="ic ic-m ic-home" />`，不要用 `.ic` 单类做底座。**

2. **原型用 HTML 标签选择器，生成器已补类名桥接**
   原型大量写 `.st b` / `.gh b` / `.p-act div` / `.zqc p`，WXML 没有 `b/p/div`。
   生成器会自动输出等价类名版：`.st b, .st .b`、`.p-act div, .p-act .d`。
   映射：`b|strong → .b`、`p → .p`、`em → .em`、`i → .i`、`div → .d`、`span → .sp`、`small → .sm`。
   **页面里用 `<text class="b">` / `<view class="d">` 就能命中，不必每页手抄桥接样式。**

3. **`position:fixed` 只给目标元素本身**
   `.fbar` / `.footbar` / `.mask` / `.sheet` / `.fab2` 是 fixed；它们的子元素（`.fbar .sum` / `.fbar .btn2`）**不是**。
   生成器早期误判「选择器含 fbar 就加 fixed」，会把按钮也钉在屏幕上，已修正。

## 四、WXML 语法硬约束（踩过的坑，违反即编译失败）

| 禁止 | 原因 | 正确写法 |
|---|---|---|
| `<div>` `<span>` `<p>` `<h1>` | 小程序无 HTML 标签 | `<view>` `<text>` |
| `<br>` | 被解析为未闭合标签 → 编译失败 | 用多个 `<view>`，或 `<text>\n</text>` |
| `bindtap="fn(a)"` | 不执行 | `bindtap="fn" data-a="{{a}}"`，方法里读 `e.currentTarget.dataset.a` |
| `wx:for` 无 `wx:key` | 告警 + 复用错乱 | `wx:key="key"` 或 `wx:key="*this"` |
| 双花括号内写 `&&`/`\|\|` | 支持但易错 | 尽量在 ts 里算好，wxml 只做简单判断 |
| `class="a {{cond ? 'b' : ''}}"` | 支持，但注意空格 | 保持单空格分隔 |

> **注释**：`<!-- -->` 可以用。**不要**在 wxml 里写 `<br>`。

## 八、已知风险（交给后续 agent 的「待修清单」种子）

1. **`--mc` / `--p` 内联变量**：`.mring`（环形进度）依赖 `style="--mc:#1FA97A;--p:60"`，小程序可能不生效 → 改用 canvas 或 CSS `conic-gradient` 固定色，或改成线性 `.bar`。
2. **`.sheet` 底部弹层**：需 `catchtouchmove` 防穿透滚动。
3. **`pgMap` 腾讯地图 GL JS**：小程序无 DOM，**必须改 `map` 原生组件** + `wx.getLocation`；原型的 key 代理模式在小程序不适用（走 `app.json` 的 `requiredPrivateInfos: ["getLocation"]`）。
4. **`pgKit` 不实现**。
5. **`repair/*` 三页保留旧实现**，与新体系类名混用无冲突（不同类名）。
6. **`service/category` 旧页保留**：hall 建好后其职责被替代，暂不删（删除需同步 `service-grid.ts` 的 `targetPath`）。
7. **图标缺失**：原型有 83 枚，若页面用到 `.ic-xxx` 不存在，图标空白但不报错；用 `grep` 确认。
8. **`fbar`/`footbar` fixed 遮挡**：根节点必须加 `.page--fbar`。
9. **`tsc --noEmit` 严格模式**：`strict/noUnusedLocals/noUnusedParameters` 全开，未用变量也报错。跑 `npm run typecheck` 看全量错误。
10. **`.gitignore` 曾过滤 `cloudfunctions/*/shared/`**：已修，勿再加回（会导致云函数运行时 `Cannot find module`）。
