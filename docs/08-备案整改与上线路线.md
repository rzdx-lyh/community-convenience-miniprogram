# 08-备案整改与上线路线（从驳回 → 被搜到）

> 生成：2026-10-17｜目标：**正式上架 + 可被微信搜索到（长期运营）**
> 当前状态：备案被驳回（名称/备注/证件背景 3 项）｜体量：个人主体

---

## 0. 先看清完整链路（重要）

```
改名（个人性质）
   ↓
重提备案 → 通过          ← 硬门槛：没有它不能发布
   ↓
微信认证                 ← 硬门槛：没有它「不能被搜索」
   ↓
提交正式审核 → 发布      ← 上架
   ↓
被微信搜到
```

> ⚠️ 很多人以为"备案通过就能被搜到"——**不是**。后台明确写着：**"完成微信认证后，账号可获得'被搜索'和'被分享'能力"**（约 300 元/年，以后台显示为准）。

---

## 第一步 · 整改这次驳回的 3 项（今天就能做）

| # | 项 | 2 次驳回状态（10-18） | 怎么改 |
|---|---|---|---|
| 1 | **小程序名称** | ❌ 仍未过 | 改成**纯个人性质**：**邻里小助手** / 邻里百事通 / 街坊工具箱（❌「服务/商城/平台/企业/中心/工作室」一律不行） |
| 2 | **小程序备注** | ❌ 仍未过 | **整段删空**（是删，不是改） |
| 3 | **承诺书** | ❌ 新增 2 条 | 见下方「承诺书规范」 |
| — | 主体负责人证件 | ✅ 本次已通过 | 保持原样 |

**承诺书规范（本次新增，2 条驳回）**

| 驳回点 | 要求 |
|---|---|
| 承诺书**非原件** | 必须是**彩色原件拍照**或**彩色原件扫描件**；❌ 不要截图（会有鼠标、缩放比例、水印等无关内容） |
| **签名**不符合要求 | **本人 / 法人手写签名**，**正楷、勿连笔、勿涂改**（也可用签名章） |

操作步骤：
1. 备案页**下载承诺书模板** → A4 打印
2. **手写签名**：正楷、一笔一划、不连笔、不涂改
3. 用手机**拍纸质原件**（或扫描仪**彩色扫描**）：四角完整、无阴影无反光、画面里**不要出现鼠标/桌面杂物**
4. 直接上传这张原图；**不要截图转发**（截图必带缩放比例/水印 → 判"非原件"）

**备注文案（备注是选填项——能删就删；仅当系统强制必填时用）**

| 版本 | 文案 |
|---|---|
| **极简（最稳）** | 个人开发的信息查询工具。 |
| **中等（推荐）** | 个人开发的邻里信息查询工具，可查看社区通知公告、查询常用电话号码、填写报修信息。 |
| **详细（信息最全）** | 个人开发的邻里信息查询工具，功能包括查看社区通知公告、查询常用电话号码、填写并提交报修信息、浏览社区资讯，以及日常办事问答，供本人及邻里日常使用。 |
| 安全变体（避开"社区"） | 个人开发的小区信息查询工具，可查看小区通知公告、查询常用电话号码、填写报修信息。 |

> ✍️ **写法原则**：只写「**看 / 查 / 填 / 浏览 / 记录**」这类动作 + 具体对象（通知、公告、电话号码、报修信息），**不写**"服务、提供、经营、商业"，也不写"不涉及经营"这种自我说明。

> ⛔ **禁用词**：服务 / 经营 / 商城 / 平台 / 企业 / 公司 / 中心 / 工作室 / 提供 / 收费 / 商业 / 便民服务——出现任一都可能被判"非个人性质"。
> ⛔ 也别写"不涉及经营性活动"——**"经营"两个字本身就是触发词**（上次驳回很可能就是这个）。

⚠️ **改名额度**：个人主体**一年 2 次**。先确认"猎奇便民服务"是否已生效——若已生效只剩 1 次，务必选准；若仍在审核中，需等审核结果再改。

| 项 | 现在 | 改成 |
|---|---|---|

**介绍文案（可直接抄）：**
> 面向社区居民的便民工具：查通知、提交报修、找便民电话、问社区办事。

---

## 第三步 · 重提备案

1. `设置 → 基本设置 → 小程序备案 → 去备案`
2. 按整改后的信息重填 → 提交
3. 平台初审 **1–2 工作日**
4. 收到 **12381** 短信 → **24 小时内**去 `beian.miit.gov.cn` 核验（超时驳回）
5. 通管局 **1–20 工作日**（保持电话畅通，可能回访）

---

## 第四步 · 微信认证（决定"能不能被搜到"）

1. `设置 → 基本设置 → 微信认证 → 去认证`
2. **先点进去确认个人主体是否支持、费用多少**（约 300 元/年，以后台为准）
3. ⚠️ 若个人主体**不支持认证** → "被搜到"基本无解，只能靠体验版二维码 + 投屏演示

---

## 第五步 · 提交审核 → 发布

1. `管理 → 版本管理 → 开发版本` → 选最新包 → **提交审核**（填版本描述）
2. 审核 **0.5–1 工作日** → 通过后 **发布**
3. 可选分阶段发布（5% → 100%）

---

## 第六步 · 验证真的能被搜到

发布后仍需满足：
- [ ] `设置 → 基本设置 → 隐私与安全 → 通过名称搜索此小程序` **处于开启**
- [ ] 微信认证**已通过**（未认证会限制被搜索）
- [ ] 刚发布有 **1–2 天收录延迟**，别急
- [ ] 用**完整名称**搜索（搜关键词不一定出）

---

## 时间现实（对齐大赛 10-25）

| 环节 | 耗时 |
|---|---|
| 整改（改内容/重拍证件） | 今天可完成 |
| 备案审核 | **1–20 工作日**（乐观 3–7） |
| 微信认证 | 1–3 天 |
| 审核发布 | 0.5–1 天 |

> ⛔ **10-25 前跑完整条链路有风险**（备案时长不可控）。**体验版保底仍然有效**——即使赶不上正式上架，演示和提交材料都不受影响。
