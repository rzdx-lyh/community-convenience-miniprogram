# 社区便民微信小程序 · 产品方案（PRD）

> 作者：产品经理（草稿）｜日期：2026-10-12｜状态：待用户确认（G2）
> 上游：docs/01-项目拆解方案.md（Lead 代拟）+ docs/00-环境与资源速查.md

## 1. 一句话定位
面向社区居民（含老年人）的便民小程序：**报修有人管、办事有人答、电话随手查**。

## 2. 目标用户与场景
| 用户 | 场景 | 痛点 |
| --- | --- | --- |
| 居民（含老人） | 水管坏了要报修、想问怎么办医保、找物业电话 | 打电话占线、跑物业远、办事流程不清楚 |
| 老人（重点） | 不会打字、字小看不清 | 数字化门槛高 |
| 物业人员 | 接收报修、派单、反馈进度 | 电话/微信群报修记录散乱 |
| 网格员/社区 | 发通知、组织活动 | 触达率低 |

**适老化是本作品差异点**：全局"关怀模式"（大字 + 语音播报 + 一键拨号）。

## 3. 功能清单（P0 全部 / P1 精选 / P2 不做）

### P0 必做（本次交付）
| # | 功能 | 验收标准 |
| --- | --- | --- |
| 1 | 微信登录 + 个人资料 | 授权登录即建档；可编辑楼栋/手机号 |
| 2 | 报修创建（AI 摘要） | 拍照/选图+描述→提交→AI 自动生成摘要；1 分钟内收到进度订阅消息 |
| 3 | 报修列表/详情/取消 | 状态筛选；时间轴；pending 可取消 |
| 4 | 物业端工单处理 | 派单/处理/完成，状态机正确；完成通知报修人 |
| 5 | AI 智能问答（RAG） | 社区办事指南问答；有引用来源；AI 不可用时降级兜底+电话 |
| 6 | 便民电话簿 | 分类+一键拨号 |
| 7 | 社区通知/活动 | 列表+详情+分类 |
| 8 | 关怀模式 | 一键切换大字+语音播报，设置持久化 |
| 9 | 隐私政策弹窗 | 首次登录展示并记录同意 |

### P1 应做（有余力再做）
- 报修图片 AI 描述（视觉模型，无免费额度则降级为文字分类）
- 活动报名（本地记录，不做支付）
- 问答"有用/无用"反馈统计（已含入契约）

### P2 不做（明确排除，防范围蔓延）
- 微信支付/缴费、社区团购、二手置换、快递代收、积分商城、管理员后台（用云开发控制台代替）

## 4. 核心流程
```
主流程A（报修）：
首页 → 我要报修 → 选分类/拍照/描述 → 提交(AI摘要) → 工单列表
  → 物业受理派单(assigned) → 处理中(processing) → 完成(done)
  → 订阅消息通知报修人 → 详情查看/评价

主流程B（AI问答）：
首页/AI助手 → 输入或语音提问 → 知识库检索 → 大模型生成回答
  → 展示答案+来源 → 有用/无用反馈
  （无命中/超时 → 降级兜底话术+便民电话一键拨号）

主流程C（适老）：
我的 → 开启关怀模式 → 全局大字号+语音播报 → AI助手页自动朗读回答
```

## 5. AI 能力设计（评分权重 20%，重点）
| 能力 | 落点 | 技术方案 | 兜底 |
| --- | --- | --- | --- |
| RAG 智能问答 | 办事指南/物业电话/流程咨询 | 云函数→大模型 API；知识库存云数据库+JSON；关键词匹配检索（零成本） | 无命中/超时→兜底话术+电话 |
| AI 工单摘要 | 报修创建 | 大模型对描述做摘要+分类校验 | 失败不阻断创建，用原文 |
| 适老化语音 | AI 助手页 | 微信同声传译插件（免费） | 文字输入始终可用 |

**Prompt 管理**：`cloudfunctions/shared/prompts.ts` 统一维护，回答固定带"AI 生成仅供参考"。

## 6. 运营与商业闭环（评分权重 15%+10%）
- 拉新：社区海报二维码、物业协助推广、种子用户（社区网格员）
- 留存：通知公告触达（订阅消息）、便民电话簿高频使用、活动日历
- 模式：公益属性为主，向社区输出"数字化便民工具"价值；决赛答辩讲"可复制到其他社区"
- 北极星指标：周活跃报修工单数、AI 问答解决率

## 7. 隐私与合规
- 仅收集：openid、昵称、手机号（加密）、楼栋号；最小必要
- 《隐私政策》+《用户协议》页面，首次登录弹窗同意
- UGC（工单描述）接 msgSecCheck 先审后发
- AI 回答固定免责声明

## 8. 与大赛评分对齐
- 技术实现（25%）：TS+分层架构+单测+契约驱动
- AI 融合（20%）：RAG 问答真实解决办事咨询，非贴标签
- 创新设计（20%）：适老化+AI 问答+社区治理场景
- 场景落地（15%）：真实社区场景+物业闭环+可复制叙事
- 体验增长（10%）：关怀模式+订阅消息+分享
- 材料完整（10%）：docs/ 全量产出+测试记录+演示视频脚本
