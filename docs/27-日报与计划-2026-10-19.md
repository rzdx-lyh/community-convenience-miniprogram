## 二、今天踩的坑（明天别再踩）

| 坑 | 结论 |
|---|---|
| 云函数 require 路径 | 必须 `./shared/...`。写 `../shared/` 本地能跑、上传必崩。`cloud-preflight.mjs` 已死守 |
| 自定义组件用全局图标 | json 必须加 `"styleIsolation": "apply-shared"`，否则图标全空白 |
| WXML 不支持 `<br>` | 被解析为未闭合标签 → 编译失败。用两个 `<view>` 块代替 |
| 编译校验只有 `cli preview` 可信 | `cli upload` 失败也返回 √。今天**做了负向对照**：故意插 `<br>`，CLI 确实报错 → 证明检查真实生效 |
| 服务项改名会炸测试 | `hall-search.test.ts` 有一条「别名目标必须真实存在」。改名必同步 `SEARCH_ALIASES` |
| 随机 id 会撞 `wx:key` | `Date.now() + random(1000)` 在同毫秒 200 次连点约 9% 撞号 → 已改自增序号兜底 |
| 版本守卫拦注释 | 源码注释里出现非当前版本号即测试失败。升版清单见 `MEMORY.md` |
