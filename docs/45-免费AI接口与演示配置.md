# 免费 AI 接口与演示配置

> 目标：比赛演示优先使用免费额度或免费模型；没有 Key 时仍然可以完整演示 Agent 工具链。

## 1. 无 Key 也能演示

以下能力不依赖付费大模型：

- Agent 意图规划
- 社区知识库检索
- 地图最近服务点
- 电话簿查询
- 通知查询
- 报修草稿生成
- 来源引用
- 下一步操作
- 医疗/法律/紧急安全话术

没有大模型 Key 时，qa:agent 会使用工具结果直接生成结构化答案，degraded=true，不会空白或报错。

## 2. 通用 OpenAI 兼容配置

云函数环境变量：

```text
AI_API_KEY=你的免费 Key
AI_API_URL=https://服务商/v1/chat/completions
AI_MODEL=免费模型名
AI_TIMEOUT_MS=8000
```

兼容旧配置：

```text
DEEPSEEK_API_KEY=...
```

优先级：AI_API_KEY > DEEPSEEK_API_KEY。

## 3. 可选免费模型示例

具体免费额度和模型名称以服务商当期活动为准：

| 服务商类型 | 示例模型 | 说明 |
|---|---|---|
| SiliconFlow | Qwen 系列小模型 | 注册后部分模型有免费额度 |
| OpenRouter | 以 :free 结尾的模型 | 免费模型可能限流 |
| ModelScope | Qwen 系列 | 以平台当期免费额度为准 |

建议演示前固定一个已验证可用的免费模型，避免现场切换。

## 4. 多模态视觉模型

```text
VISION_API_KEY=...
VISION_API_URL=https://服务商/v1/chat/completions
VISION_MODEL=视觉模型名
VISION_TIMEOUT_MS=10000
```

未配置时，报修页仍可正常提交，只显示“请手动填写”，不会阻断流程。

## 5. 演示建议

1. 先用无 Key 模式录制 Agent 工具调用和来源引用。
2. 再配置免费模型录制自然语言生成效果。
3. 多模态部分可配置免费视觉额度，或如实演示降级到人工填写。
4. 不在视频中展示 Key、云环境密钥或真实居民信息。

## 6. 安全约束

- Key 只放云函数环境变量，不进入前端和 Git。
- 不把真实手机号、身份证、健康档案发送给第三方模型。
- 所有 AI 回答保留来源和人工兜底。
- 医疗、法律、紧急问题始终走固定安全话术。
