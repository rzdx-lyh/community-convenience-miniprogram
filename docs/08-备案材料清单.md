## 0. 动手前先看 3 个关键点 ⚠️

### ① 名字很可能被驳回（本项目最大风险）
备案要求「**小程序名称与经营内容一致**」，这是驳回**高发点**。当前名称 **"风残烛火心碎"** 与"社区服务"完全不沾边，**大概率被审核驳回**。
- **建议**：备案前先把小程序名称改为与业务一致的名称，例如 **「XX社区便民服务」**（XX 可为你所在社区/团队名）。
- 更名规则：个人主体小程序**一年可改 2 次名称**，且需通过名称审核。请先改再备案。

### ② 主体选"个人"还是"企业"，决定一半字段
- **个人主体**：只要身份证；但**不能开支付/交易/经营性内容**（本项目无支付，OK）。服务类目是否可选"社区服务"**以后台实际可选为准**。
- **企业/个体户主体**：要营业执照 + 法人证件 + 可能授权书；类目权限更广。
- **要你定**：以谁的名义备案？（参赛主体）

### ③ 备案前置条件（后台会自动检测，不满足进不去）
- 小程序需**已完成认证**（后台"去备案"时会自动检测；若提示需认证，先完成微信认证）。
- 主体名下**无在途备案**。
- 备案成功前**不能提交正式审核/上架**，但**不影响体验版使用**（评委扫码照旧）。

## 0.5 ⚠️ 类目更正（2026-10-15 官方核实，务必看）

> 依据：微信官方《小程序备案服务内容选择指引》+ 服务类目表核实。

### ① 备案表里**没有"社区服务"**这个二级类目
- 官方**备案"服务内容"**表里，「生活服务」下**不存在"社区服务"**。
- 「生活服务」下 **个人主体可选**的只有：**工具、丽人、宠物、法律咨询（需资质）、摄影/扩印、其他**；其余多为"**不建议选择**"。

### ② 审核"服务类目"里**有"生活服务-社区服务"**，但更适合**单位主体**
- 小程序**审核类目**表里确实有「生活服务 > 社区服务」（用于报修/物业/社区通知等场景）。
- 但该表说明：**生活服务类目适用于商业机构**（如便利店、家政公司）；社区事务预约类更贴"**政务服务**"。
- → **单位（企业/个体户）**主体选它更稳；**个人主体**通常选不上，会被驳回。

### ③ 本项目功能与"个人主体"类目匹配（2026-10-15 代码核实后更正）
| 功能 | 性质 | 风险 |
|---|---|---|
| 社区圈子 | **只读信息展示（无 UGC）**——契约明确"发帖/评论本期不做""禁止客户端直写" | ✅ 低 |
| 通知公告 / 便民电话簿 | 只读展示 | ✅ 低 |
| 报修工单 | 表单提交 + 图片上传（非公开 UGC） | ✅ 低 |
| AI 问答 | AIGC 内容 | 🟡 类目归属略模糊 |

> 结论：本项目**无公开 UGC**，类目风险比预想低。**单位主体**走「生活服务-社区服务」最贴切；**个人主体**建议选「工具」（备案"生活服务"下个人仅 工具/丽人/宠物/法律咨询/摄影扩印/其他 可选）。

## 3. 前置审批类目（本项目 = 无）

以下行业**才**需要前置审批文件，本项目均不涉及，填"以上都不涉及"即可：
- 新闻 → 《互联网新闻信息服务许可证》
- 出版 / 网络文学 → 出版类许可
- 药品 / 医疗器械 → 《互联网药品信息服务资格证书》
- 网约车 → 《网络预约出租汽车经营许可证》
- 食品经营 → 《食品经营许可证》
- 文化 / 广电 / 教育 / 金融 等

> 本项目为社区便民信息 + 报修 + 电话簿 + AI 问答，**无交易、无支付、无上述行业内容 → 无需前置审批**。

## 4. 备案流程与时效（5 步）

| 步骤 | 环节 | 时长 | 关键动作 |
|---|---|---|---|
| 1 | 备案信息填写 | — | mp.weixin.qq.com → **设置 → 基本设置 → 小程序备案 → 去备案** |
| 2 | 平台初审 | 1–2 工作日 | 保持电话畅通；资料问题会退回补正 |
| 3 | **工信部短信核验** | **24 小时红线** | 收到 **12381** 短信后，登录 `https://beian.miit.gov.cn/` 完成核验；**超时即驳回** |
| 4 | 通管局审核 | **1–20 工作日** | 部分省份会**电话回访**负责人，问"小程序做什么"→ 如实回答，别当推销挂断 |
| 5 | 备案成功 | — | 下发备案号（如"粤ICP备XXXXXXXX号"），后台显示"已备案"，**此后才可提交正式审核** |

> ⏱ **时效判断**：广东/浙江等地较快（约 3–7 工作日），一般 7–15 工作日。**今天(10-15)提交，乐观 10-22~10-24 出号**；能否赶在 10-25 前正式上线**存在不确定性**。

## 6. 常见疑问

- **备案和体验版冲突吗？** 不冲突。备案期间**体验版可继续扫码使用**；只是**不能提交正式审核/上架**。
- **要花钱吗？** 小程序备案**免费**（微信认证可能单独收费，若后台要求）。
- **没有网站/域名也要备案吗？** 要。小程序备案与网站备案独立，只要上架就需备案（本项目走云开发，**无需**服务器域名）。
- **多小程序能共用一个备案号吗？** 同一主体名下多个小程序一般可关联同一主体备案，具体以后台规则为准。
