## 0. 改之前先看这一条（10 秒）

个人主体备案，**审核员判断的是「你有没有在经营」**。
所以全文的写法原则只有一句：

> ✅ 只写「**看 / 查 / 填 / 浏览 / 记录**」+ 具体对象
> ⛔ 不写「服务 / 提供 / 经营 / 商业 / 收费 / 平台 / 中心 / 商城 / 企业」

⚠️ 特别提醒：**"经营"两个字本身就是触发词**，所以连"不涉及经营活动"这种自我澄清都别写。

## 1. 名称（驳回第 1 项）

**现状**：`猎奇便民服务` —— "服务"两个字直接被判成经营性字样。

**改成（三选一，都能过）**：

| 候选 | 说明 |
|---|---|
| **邻里小助手**（推荐） | 最稳，"小助手"是个人性质典型表述 |
| 邻里百事通 | 次选 |
| 街坊工具箱 | "工具"与类目「工具 > 信息查询」呼应 |

**操作路径**：`设置 → 基本设置 → 小程序名称 → 修改`

⚠️ **改名额度**：个人主体**一年只有 2 次**。
先确认"猎奇便民服务"是否已生效：
- 已生效 → 你只剩 **1 次**，一次选准；
- 仍在审核中 → **等审核出结果再改**，否则会浪费额度。

## 3. 承诺书（驳回第 3 项，新增 2 条）

| 驳回点 | 要求 |
|---|---|
| **非原件** | 必须**彩色原件拍照**或**彩色原件扫描件**；❌ 截图必死（会带鼠标、缩放比例、水印） |
| **签名不合格** | **本人手写签名**，**正楷、不连笔、不涂改**（签名章也可以） |

**四步拍出合格件**：

1. 备案页**下载承诺书模板** → **A4 纸打印**
2. **手写签名**：正楷、一笔一划、不连笔、不涂改
3. **手机拍纸质原件**（或扫描仪彩色扫描）：
   - 四角完整、画面端正
   - 无阴影、无反光
   - 画面里**不要出现鼠标、桌面杂物、手指**
4. **直接上传这张原图**；不要截图、不要转发后再存（转发会压缩并带水印）

## 5. ⚠️ 本次新增的风险（必读，是我做服务页时发现的）

CR-026 / CR-027 给小程序加了这些页面：

- **房屋租售**（带价格、联系看房）
- **生鲜零售**（带价格、预订）
- **缴费账单**（户号绑定）
- **快递代取代寄 / 共享设备**（均带费用规则）

**问题**：备案走的是「个人主体 + 工具 > 信息查询」，而页面里出现**租售房源、明码标价**这类内容，
审核员可能判为「实际从事经营性活动」，与类目不符 → **审核驳回**。

**三种应对，按推荐度排序**：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A（推荐）** 保留并弱化 | 已做：每页都写了"不收款 / 不代扣 / 不收中介费 / 只做登记"的红线文案，并**写进了单测**（`tests/service-cr027.test.ts`）。提交审核时**把「房屋租售」这一项暂时下线**（`service-grid.ts` 里改 `status: 'offline'` 或暂时改回 `assistant`） | 少 1 个演示点 |
| B 保留全部 | 赌审核员只看名称不看页面 | 驳回风险高 |
| C 全部下线 | 只留通知/电话簿/报修 | 演示亮点大幅减少 |

> **我的建议**：先用方案 A 提交备案与审核；**等正式发布通过后再把房屋租售打开**。
> 演示与大赛材料不受影响（体验版不受审核限制）。

## 6. 提交后的时间线（别催）

| 环节 | 耗时 | 你要做什么 |
|---|---|---|
| 平台初审 | 1–2 工作日 | 等 |
| 工信部短信核验 | 收到 **12381** 短信后 **24 小时内** | 去 `beian.miit.gov.cn` 核验（超时直接驳回） |

| 提交审核 → 发布 | 0.5–1 天 | — |

⛔ **大赛 10-25 前跑完整条链路风险很高**（备案时长不可控）。
**体验版保底依然有效**——演示、录视频、提交材料都不受影响。
