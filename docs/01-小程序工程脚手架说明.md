## 三、已代做的决策（占位，可被闸门推翻）

1. **tabBar = 首页 / AI助手 / 报修 / 我的（4 项纯文字）**
   UI 问卷 Q12 推荐「首页/服务/AI助手/我的」，但「服务」聚合页不在冻结的 8 页清单内，
   故按 Q12 兜底方案「报修直连 Tab」落地。**纯文字 tabBar 合法**，图标待 UI 切图（81×81 双态 png）。
   若 G3 设计稿定稿为其他结构，改 `app.json` 的 `tabBar.list` 一处即可。
2. **主题色占位**：tabBar 选中色 `#C0522F`、导航底色 `#FAF6F1`（UI 推荐色板 A）；
   `app.wxss` 变量仍为 FE 规范 §7.8 的占位蓝 —— design tokens 落盘后**只换变量值**。
3. **kb 文件名按 v1.1 契约**：`shared/kb/kb.json`（06-后端规范的 `kb/data.json` 以契约为准）。
4. **`wx-server-sdk: "latest"`**：BE-0 开工时可锁定具体版本。
