## 1. 结论

在“数据不离开微信/腾讯生态”的前提下，建议采用：

> **统一 AI 网关 + 微信官方能力优先 + 腾讯云能力兜底 + 本地规则最终兜底**

建议新增云函数：

```text
cloudfunctions/ai-gateway
```

统一负责：

- 图片识别、OCR、通用图片问答；
- 方言语音识别、方言语音合成；
- 免费额度统计、限流、缓存；
- 内容安全和隐私检查；
- 失败降级与转人工。

客户端不允许直接调用任何 AI 服务，所有请求必须经过云函数。

## 2. 需求范围

### 2.1 识图场景

| 场景 | 输入 | 输出 |
| --- | --- | --- |
| 楼道堆物 | 居民/管理员拍照或聊天图片 | 是否堆物、风险等级、描述、建议分类 |
| 设施损坏 | 图片 | 设施类型、损坏现象、严重程度、报修摘要 |
| 垃圾满溢 | 图片 | 垃圾类型、满溢程度、位置提示 |
| 安全隐患 | 图片 | 隐患类型、风险等级、处置建议 |
| 药品识别 | 药盒/说明书 | 药品名、规格、厂家、用法原文、风险提示 |
| 票据识别 | 收据/缴费单 | 类型、金额、日期、项目、编号 |
| 通用图片问答 | 图片 + 问题 | 基于图片内容的回答 |

### 2.2 图片来源

- 居民手机拍照；
- 微信聊天图片；
- 管理员后台上传；
- 后续可接入云存储临时 fileID。

### 2.3 方言

首期目标：

```text
已确认方言：粤语、客家话、潮汕话、雷州话、阳江话
```

方向：

- 方言语音 → 普通话文字；
- 普通话文字 → 方言语音；
- 动态回复内容方言播报。

场景：

- 报修；
- 服务搜索；
- AI 问答；
- 通知播报；
- 后台语音录入。

### 2.4 用户与双端分工

客户端与管理端同时开放：

- 客户端面向老人、青少年、普通居民和家属；
- 客户端负责 AI 识图、方言转换、报修、搜索和 AI 问答；
- 管理端面向社区工作人员、物业人员和社区管理员；
- 管理端只负责数据管理、审核、派单、统计和审计；
- 管理端不调用 AI，不占用客户端 50 次识图和 100 分钟语音额度。

## 3. 可行性边界

### 3.1 费用边界（免费优先 + 少量按量）

已确认：

- 识图、OCR、ASR、TTS 和图片问答仍以免费额度优先；
- 联网检索保持开启；
- 联网检索免费额度不足时，允许少量按量付费；
- 只有联网检索允许自动进入按量付费；
- 其他 AI 能力不得自动切换付费服务；
- 联网检索必须设置每日调用上限和月度预算上限。

已确认值：

- 联网检索：最多 10 次/天；
- 月度预算：¥20/月；
- 达到 80%：管理员告警；
- 达到 100%：停止联网检索，回退知识库/文字/人工。

### 3.2 方言风险

| 方言 | 预估可行性 | 说明 |
| --- | --- | --- |
| 粤语 | 较高 | 常见方言，优先验证 |
| 雷州话 | 待验证 | 广东区域方言，需确认官方 ASR/TTS 覆盖 |
| 阳江话 | 待验证 | 广东区域方言，需确认官方 ASR/TTS 覆盖 |
| 客家话 | 待验证 | 识别和合成覆盖不确定 |
| 潮汕话 | 风险最高 | 免费官方能力可能不完整支持 |

原则：

- 未验证支持的方言不能对外宣称支持；
- 潮汕话、客家话若不可用，回退普通话文字或人工转写；
- 语音合成失败时回退普通话语音或纯文字；
- 方言合成需提示“机器合成，可能存在口音差异”。

### 3.3 存量 AI 迁移（已确认）

当前项目已有 DeepSeek 与网页检索能力，但这两项都会离开微信/腾讯云生态。

已确认处理方向：

- 将文本问答模型迁移到腾讯云 CloudBase AI 或腾讯云内可用模型；
- 将网页检索迁移到腾讯云生态内的搜索/智能体能力；
- 联网检索保持开启；免费额度不足时允许少量按量付费，但必须有每日调用上限和月度预算上限；
- 不再直接请求 `api.deepseek.com`；
- 不再直接请求 360、搜狗、Bing 等外部搜索页面；
- 保持 `qa:ask` 的出参结构不变，前端不需要重写；
- 在迁移完成前，不得把现有外网 AI 能力作为正式版依赖。

建议增加模型适配层：

```text
cloudfunctions/qa
  ├── provider-cloudbase.js
  ├── provider-tencent-ai.js
  ├── provider-disabled.js
  └── index.js
```

这样可以在不修改前端的情况下切换模型供应商。

## 5. 能力路由

### 5.1 识别优先级

```text
微信官方 OCR / 图像能力
→ 微信服务市场 OCR / 图像识别
→ 腾讯云 OCR / 图像识别
→ CloudBase 内可用多模态模型
→ 本地规则 + 人工确认
```

### 5.2 方言优先级

```text
微信同声传译等官方语音能力
→ 腾讯云 ASR / TTS 方言能力
→ CloudBase 内可用语音模型
→ 普通话音转文字
→ 文字输入 / 人工转写
```

### 5.3 路由约束

- 单次请求最多尝试 2 个供应商；
- 主服务超时后再尝试备用服务；
- 除联网检索外，免费额度不足时不得切换付费服务；联网检索必须受预算硬上限约束；
- 返回结果必须包含 `provider`、`degraded`、`reason`、`quotaRemaining`。

## 6. 识图流程

```text
选择场景
→ 拍照 / 选择图片
→ 图片压缩
→ 上传临时云存储
→ 身份、额度、内容安全检查
→ 识图 / OCR / 图片问答
→ 结构化结果
→ 管理员人工确认
→ 写入工单或票据记录
→ 按业务规则清理临时文件
```

### 6.1 结构化结果示例

```json
{
  "scene": "corridor_clutter",
  "hasIssue": true,
  "riskLevel": "high",
  "description": "楼道内堆放纸箱和旧家具，影响通行",
  "suggestedCategory": "public",
  "suggestedTitle": "楼道堆物影响通行",
  "needManualReview": true
}
```

### 6.2 药品识别限制

- 只做 OCR 和一般信息整理；
- 不提供诊断、处方或剂量调整建议；
- 识别不确定时提示查看说明书或咨询医生；
- 药品图片不得进入公开圈子；
- 药品原图允许作为业务附件保留，仅授权人员可见；
- 高风险问题切换固定安全话术。

### 6.3 票据识别限制

- 不自动发起支付；
- 不保存完整银行卡号；
- 金额、日期和编号必须允许人工校正；
- 票据原图允许作为业务附件保留；
- 附件仅授权工作人员和业务相关用户可查看；
- 票据附件按业务保留期限管理。

### 6.4 通用图片问答限制

- 对所有客户端用户开放；
- 纳入社区识图总池，并增加单用户防刷上限；
- 不处理身份证、银行卡、密码和私密照片；
- 返回“AI 识别，仅供参考”；
- 医疗、法律、财务问题转人工或固定安全话术。

## 7. 方言转换流程

### 7.1 方言语音转普通话文字

必须先选择方言，再允许录音或上传语音。

```text
选择/确认方言
→ 录音
→ 格式检查
→ ASR
→ 方言词归一化
→ 社区热词纠错
→ 普通话文本
→ 用户确认
→ 搜索 / 报修 / AI 问答
```

### 7.2 普通话文字转方言语音

```text
普通话文本
→ 分句
→ 敏感内容检查
→ 方言选择
→ TTS
→ 临时音频
→ 播放
```

要求：

- 支持动态回复内容；
- 单次文本建议不超过 120 字；
- 超长文本自动分段；
- 失败时回退普通话语音或文字；
- 含隐私内容不缓存音频。

### 7.3 方言热词

建议新增集合：

```text
dialect_terms
```

字段：

```text
dialect / raw / standard / communityId / enabled / sort
```

示例：

```text
落雨 → 下雨
食饭 → 吃饭
唔该 → 谢谢 / 麻烦
```

## 11. 客户端额度与限流

试点期总量已确认：

```text
客户端识图：50 次/社区/天
客户端语音：100 分钟/社区/天
管理端 AI：0 次
```

建议拆分：

| 能力 | 客户端全社区/天 | 管理端/天 |
| --- | --- | --- |
| 场景图像识别 | 20 次 | 0 |
| OCR（药品/票据） | 20 次 | 0 |
| 通用图片问答 | 10 次 | 0 |
| 方言 ASR | 70 分钟 | 0 |
| 方言 TTS | 30 分钟 | 0 |
| 合计 | 50 次 + 100 分钟 | 0 |
| 单用户防刷上限 | 识图 5 次/人/天；语音 10 分钟/人/天 | 0 |

规则：

- 全社区按天统计总量，同时按单用户设置防刷上限；
- 缓存命中不扣配额；
- 达到上限后只允许文字输入和人工处理；
- 联网检索允许按预算进入少量按量付费；其他能力不自动切换付费 API；
- 通用图片问答先于其他能力耗尽时停止，不挤占报修识图和 OCR；
- 语音额度由 ASR 与 TTS 共享总上限 100 分钟；
- 管理端不得调用 AI 接口。

## 14. 隐私与安全

- 只调用微信/腾讯云生态内服务；
- 不接入境外或第三方免费 AI；
- 图片和语音使用临时云存储；
- 处理完成后按业务规则删除；
- 日志不记录原图、完整语音、身份证号、银行卡号、完整手机号；
- 未成年人默认不开放通用图片问答；
- 长者“独居”和健康信息仅授权人员可见；
- 药品和医疗问题不提供诊断；
- 票据识别不自动支付；
- 管理员操作写入审计日志。

## 15. 降级策略

```text
官方主能力
→ 腾讯云备用能力
→ 本地关键词/规则
→ 手动输入
→ 转人工
```

具体表现：

- 识图失败：提示手动填写描述，保留已选图片；
- OCR 失败：允许管理员手动录入；
- 方言识别失败：切换普通话或手动输入；
- TTS 失败：回退普通话语音或纯文字；
- 其他 AI 免费额度耗尽：提示明天再试或联系人工；联网检索预算耗尽：回退知识库、文字或人工；
- 服务超时：一次重试后转人工。

## 18. 验收标准

### 识图

- 客户端用户可上传 4 类现场图片；
- 返回类型、描述、风险等级和建议分类；
- 结果必须人工确认；
- 免费额度耗尽时正确降级；
- 数据不离开微信/腾讯云生态。

### 方言

- 用户先选择方言，再完成 ASR；
- 支持动态文本 TTS；
- 不支持的方言明确提示；
- 失败时可切换文字输入；
- TTS 失败时可回退普通话；
- 管理端不触发 AI 请求。

### 隐私

- 日志不含原图、完整语音和敏感号码；
- 临时媒体按规则清理；
- 未成年人、长者、药品和票据场景有专门限制；
- 管理员操作可审计；
- DeepSeek 与网页检索已不再作为正式版外网依赖。

- 需要通过缓存、每日限流、热点问题缓存和多种免费来源组合控制；
- 已确认接受少量按量费用，但必须设置每日调用上限和月度预算；
- 已确认联网检索最多 10 次/天，月度预算 ¥20；
- 达到 80% 告警，达到 100% 硬停止；
- 不得自动购买套餐或扩大预算；
- 其他 AI 能力额度不足时回退文字或人工。
