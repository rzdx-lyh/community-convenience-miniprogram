**② `utils/request.ts` 的硬性要求**（这是 FE-0 的核心交付）

- 函数签名建议：`request<T>(action: string, data?: object): Promise<T>`
- **接口名格式**：`"workorder:list"`，**半角冒号**（不是 `workorder.list`）
- **双通道**：读 `config/env.ts` 的 `USE_MOCK`
  - `USE_MOCK = true` → 走 `mock/` 本地假数据（**路径与真实云函数完全同名**）
  - `USE_MOCK = false` → `wx.cloud.callFunction({ name: '资源:动作', data })`
- **统一响应处理**：解包 `{code, msg, data}`
  - `code === 0` → resolve `data`
  - `code !== 0` → 按错误码给 toast 提示，reject
- **错误码文案**（照契约表，不发明新码）：

| code | 含义 | 提示文案建议 |
| --- | --- | --- |
| 0 | 成功 | — |
| 400 | 参数错误 | 信息填写有误，请检查后重试 |
| 401 | 未登录 | 请重新进入小程序 |
| 403 | 无权限 | 你没有权限执行该操作 |
| 404 | 资源不存在 | 内容不存在或已删除 |
| 429 | 请求过于频繁 | 操作太频繁，请稍后再试 |
| 500 | 服务异常 | 服务出了点小问题，稍后再试 |
| 503 | AI 降级 | （AI 场景专用，不弹错，走降级 UI） |

- **超时保护**：`wx.cloud.callFunction` 加 8s 超时，超时按 503 处理
- **日志**：每次请求记录 `action / cost_ms / code` 到 `utils/logger.ts`
