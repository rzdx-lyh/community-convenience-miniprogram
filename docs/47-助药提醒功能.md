# 助药提醒（v1.3.1）

## 1. 功能定位

助药提醒用于帮助居民记录医生或药师已经明确给出的用药计划，并提供每日服药清单、打卡和安全提示。

边界：

- 不提供诊断
- 不生成处方
- 不建议剂量
- 不替代医生或药师
- 漏服、停药、调整剂量必须咨询医生或药师
- 所有药品与打卡数据只保存在本机，不上传云端

## 2. 入口

居民端 → 健康服务 → 助药提醒

页面路径：

`pages/service/medication/index`

## 3. 功能清单

- 添加药品计划
- 编辑、暂停、删除药品
- 每天设置 1-6 个服用时间
- 设置开始日期和可选结束日期
- 今日服药清单按时间排序
- 到点、超时、已服用、已跳过状态
- 已服/跳过打卡与撤销
- 今日完成比例和剩余次数
- 页面内到点提示
- 分享入口
- 关怀模式适配

## 4. 数据与隐私

本地 Storage：

| 键 | 内容 |
|---|---|
| `ccfMedicationPlans` | 药品计划 |
| `ccfMedicationLogs` | 近 90 天服药打卡 |
| `ccfMedicationReminderEnabled` | 提醒开关 |

数据不上传云数据库，不调用云函数，不包含真实处方或居民身份信息。

## 5. 安全规则

- 表单必须填写药品名称、剂量和医嘱说明
- 必须勾选“已按医生或药师说明填写”
- 超时提示明确写“勿自行加倍剂量”
- 页面固定展示安全与隐私提示
- 后台订阅消息模板未配置时，只使用页面内提示，不伪造微信推送

## 6. 配置

`miniprogram/config/env.ts`：

```ts
MEDICATION_TEMPLATE_IDS: []
```

如果后续申请到助药提醒订阅消息模板，将模板 ID 填入该数组即可启用微信订阅提醒。
