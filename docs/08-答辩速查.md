## 1. 一句话定位

**面向社区居民的便民服务小程序**：把「找服务、看通知、报维修、问事情、打电话」五件高频小事，收进一个不用下载 App、扫码即用的微信小程序里，并为老年人提供关怀模式。

## 3. 技术架构（评委问「怎么实现的」）

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 前端 | 微信小程序原生 + TypeScript | 9 个页面，全部 TS 严格模式 |
| 后端 | 微信云开发（云函数 + 云数据库 + 云存储） | **免服务器、免域名、免备案** |
| AI | DeepSeek 大模型 | 通过云函数中转，前端不直接接触 API Key |
| 数据 | 云数据库 8 个集合 | 公告 / 工单 / 圈子 / 电话簿 / 服务分类 / 用户 / 会话 / 反馈 |

**接口规模**：8 个云函数资源 · 19 个动作 · 8 个集合。

**调用形态**：`wx.cloud.callFunction({ name: '资源', data: { action: '动作', ...业务参数 } })`
（`data.action` 为分发键；云函数名不支持冒号，故拆成 name + action 两截）

## 4. 四个技术亮点（建议主动讲）

### 亮点一：AI 安全护栏（CR-012）—— 涉医 / 涉法 / 紧急求助三类前置拦截

> 高风险问题在**调用大模型之前**就被拦截，直接返回固定安全话术，**不经过模型生成**。

- 判定顺序：紧急求助 → 涉医 → 涉法，命中即短路返回。
- 返回 `degraded=true` + `_riskLevel`，前端气泡照常渲染安全话术原文（**不替换为兜底文案**）。
- 意义：AI 会胡说，但"胸痛怎么办"这类问题不允许胡说。**这是本产品对"AI 可靠性"给出的答案。**

### 亮点二：五级降级设计 —— 任何一层挂掉，产品仍然可用

| 降级点 | 兜底 |
| --- | --- |
| 无 API Key | 回退知识库原文 |
| 大模型超时（8s） | 回退知识库原文 |
| 内容安全接口不可用 | fail-open，不阻断发布 |
| 订阅消息模板未申请 | 静默跳过，不报错 |
| 云环境不可用 | 前端回退本地常量与内存数据 |

> 设计原则：**降级路径必须自给自足，不能依赖它正在降级的那个通道**（CR-018-b）。

### 亮点三：号码单一真源 —— 紧急号码不能以任何形式给错

- 号码真源只有一处：`cloudfunctions/shared/hotline.js`；`phonebook` 集合是其派生物，**禁止在云控制台手工编辑**。
- 替换范围精确化：**可替换 8 条**社区服务号（`020-8888xxxx` 段演示占位号）；⛔ **严禁替换 3 条**——110 / 119 / 120 是国家公开紧急号码。
- 话术与号码的每一处副本（`seed.mjs` / 前端 mock / 紧急求助兜底配置）都有自动断言守卫，防止漂移。

### 亮点四：关怀模式 —— 适老化不是把字放大

- `.care-mode` 下字号 ×1.25 并**触发重排**（宫格由 2 列转 1 列），而非整页 scale。
- 理由：整页缩放会让大字号溢出屏幕、需要横向拖动，反而更难用。

## 6. 评委提问预案

### Q：「你这个电话打得通吗？」

> 电话簿 11 条分两类：110 / 119 / 120 是**国家公开紧急号码**，真实可拨，任何环境都不改；其余 8 条是**演示环境占位数据**（`020-8888xxxx` 段），真实部署时由各社区替换为本单位实际号码。
> 号码做成了**配置化数据 + 单一真源**，而不是写死在页面里——社区接入时零改代码。这也是部署手册里为什么有一条「严禁整体替换」的红线：说"整体替换"会被执行成 11 条全换。

⚠ 口径纪律：**永远不说「部署时整体替换」**，说「可替换 8 条 / 严禁替换 3 条」。

### Q：「AI 说的准不准？出了事谁负责？」

> AI 助手有前置安全护栏：涉医、涉法、紧急求助三类问题在调大模型之前就被拦截，直接返回固定话术（如「胸痛」引导拨打 120），**不经过模型生成**。
> 非风险问题走知识库 + 大模型，回答尾部固定注入「AI 生成仅供参考」，且附来源出处可追溯。
> 定位上它是**社区办事引导**，不是医疗或法律意见——护栏就是这条边界的技术实现。

### Q：「数据是真的吗？」

> 演示环境是种子数据（`node scripts/seed.mjs` 一键生成，6 个集合）。产品本身是**数据驱动**的：公告、帖子、服务分类、电话簿全部来自云数据库，前端不写死任何业务内容，社区接入只需导入自己的数据。

### Q：「为什么用云开发不用自己服务器？」

> 社区类应用并发低、预算有限、运维人力几乎为零。云开发免服务器免备案，按量计费，且**天然打通微信登录**——这是本项目最匹配的技术选型，不是妥协。

### Q：「有没有做适老化？」

> 有关怀模式：字号 ×1.25 并重排布局（宫格转单列），不是整页缩放——整页缩放会让内容溢出屏幕需要横向拖动，对老人反而更难用。
