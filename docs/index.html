原型里值得点的地方

开局登录

未勾协议点登录会被拦下（勾选框抖动变红）；登录填的昵称会同步到圈子作者名与我的页。

智慧配餐

选目标 + 人数 + 忌口 → 生成三餐；勾「海鲜」后午餐就没有鱼虾；可换菜、可锁定；食材可一键转生鲜预订。

我的

点头像或昵称可改名字、选头像底色、写签名；家庭成员可增删；通知开关与字号（特大=关怀模式）。

圈子

4 种动态形态各自专属卡片：求助带采纳回答、闲置带价格、活动带报名进度、路况带施工状态。
