## 三、视觉与结构层已做的事

- `styles/layout.wxss`（生成物，601 条）：原型 362 个类转成小程序 WXSS，px→rpx、`inset` 展开、弹层 `fixed`、`display:none` 剥离。
- `styles/icons.wxss`（生成物，83 深色 + 26 白色）：从原型 SVG sprite 栅格化成 PNG base64。
- `app.wxss`：接入两个生成物 + 按压态工具类（`.u-hover/.u-hover-bg/.u-hover-scale`）。
- 全局 `navigationStyle: custom`；每页用 `statusBarHeight` 给 `.sbar/.nav/.pgh` 补 `padding-top`。

### 三处「有意偏移」（改样式时必须知道）

1. **原型 `.ic` 底座 → 改名 `.ib`**
   原型 `.ic` 是 40×40 圆角图标底座，`icons.wxss` 的 `.ic` 是图标本体（background-image）。同名同权重会互相覆盖，导致图标全变 80rpx 带底座。生成器已改名，**页面写图标只用 `class="ic ic-m ic-home"`**。

2. **HTML 标签选择器 → 补类名桥接**
   原型 `.st b` / `.p-act div` 在 WXML 无效（没有 `b`/`div`）。生成器自动输出 `.st b, .st .b`、`.p-act div, .p-act .d`。
   映射：`b|strong→.b`、`p→.p`、`em→.em`、`i→.i`、`div→.d`、`span→.sp`、`small→.sm`。

3. **`position:fixed` 只给目标元素本身**
   `.fbar`/`.footbar`/`.mask`/`.sheet`/`.fab2` 是 fixed，其子元素（`.fbar .btn2`）不是。

### P3 · 已知的「设计稿 vs 小程序」取舍（不是 bug）

- **发帖**：原型是底部弹层（`sheetPostNew`），小程序做成独立页 `circle/post`（体验更好）。
- **动态详情**：原型 `pgPost` 是详情页，已按此实现 `circle/detail`。
- **地图**：原型用腾讯位置服务 GL JS（DOM API），小程序改用原生 `<map>` + 本地 PNG marker（`pages/map/pin-*.png`）。
- **环形进度**：原型 `.mring` 依赖内联 CSS 变量，小程序不稳 → 已改用条形 `.bar` 或固定色 `conic-gradient`。
