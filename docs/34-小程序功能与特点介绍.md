## 1 一句话定位

面向社区（重点是中老年居民）的**一站式便民服务与信息中枢**——把报修、缴费、挂号、助餐、通知、
电话簿这些高频琐事收进一个入口，并用 AI 降低使用门槛。

---

## 2 目标用户与场景

| 用户群 | 画像 | 核心诉求 |
|---|---|---|
| 社区居民（主力） | 25–70 岁，含大量不熟悉 App 操作的中老年人 | 一件事只跑一趟：报修、缴费、挂号、办事、找电话 |
| 独居老人 / 行动不便者 | 60 岁以上，视力与操作能力下降 | 大字、少层级、一键打电话给人 |
| 物业维修人员 | 现场作业，手机操作为主 | 快速接单、看单、回报进度 |
| 社区居委会 / 管理员 | 兼职管理，非技术人员 | 发通知、看统计、改服务分类（不改代码） |

场景高度集中在五类：生活报修、政务办事、健康、邻里互助、紧急求助。它们的共同特征是——
**频次高、单次价值低、信息分散在物业群/公告栏/电话簿/政府网站四处**。居民的真实成本不在"办"，
而在"找不到入口、问不到人、跑冤枉路"。

## 4 核心功能与特点

### 4.1 首页 —— 社区"今日信息中枢"

顶部社区位置 + 搜索 + 四个快捷入口（报修/缴费/挂号/助餐），向下依次是服务分类 → 常用服务 →
附近服务 → AI 管家提醒 → 社区动态。

- **特点**：位置文案、地图距离按用户手动选择的社区位置点（楼栋/出入口）动态计算，不写死、不读取手机定位；
  AI 提醒来自工单与通知的真实关联；
  首页只是"入口"，真正的能力在下面的模块。

### 4.2 办事大厅 —— 38 项服务的统一入口

4 大类（生活基础 / 健康养老 / 便民配套 / 社区文化）· 8 板块 · 38 项服务。

- **特点一：统一预约收口**。所有「预约登记类」服务（助浴、陪护、挂号、报修等 9+ 项）指向
  **同一个三步式预约页**（服务名/选项/分类用参数传入），避免为几十个服务各写页面，是它可维护性的关键。
- **特点二：配置化驱动**。服务项名称、图标、跳转目标全部集中在 `service-grid.ts`，
  增删改服务不动任何页面代码。

### 4.3 AI 管家 —— 最大的差异化亮点

本地知识库优先 + DeepSeek 大模型 RAG 兜底，多轮对话，回答带来源标注。

- **安全护栏**：涉医/涉法/紧急求助自动拦截（问"胸痛怎么办"→ 引导拨打 120），绝不越界作答；
- **场景集群**：8 个场景卡片"点卡即带好预设问题"，降低老人组织语言的负担；
- **降级不裸奔**：AI 不可用时回退本地知识库 + 引导电话，回答永远有着落。

### 4.4 报修工单 —— 完整闭环

创建（可拍照、AI 自动生成摘要）→ 列表 → 详情 → 状态流转（待派单/已派单/处理中/已完工/取消），
每步可查，完成时订阅消息通知报修人。

### 4.5 社区地图 —— 社区位置 + 真距离

原生 `<map>`（GCJ-02），9 个服务点位；用户可在社区内手动选择位置点（6 个楼栋/出入口），
距离按所选位置 Haversine 实时计算、按近远排序，可跳系统导航。不读取手机定位
（`wx.getLocation` 申请被驳回后改为手选，见 `docs/37`）。

### 4.6 便民电话簿 —— 分类 + 一键拨号

5 类，110/119/120 真号保留并突出显示，一键拨号（老人友好）。

### 4.7 服务生态（第二梯队）

生鲜零售（购物车预订）、智慧配餐（换菜/控糖）、房屋租售（筛选/登记）、快递代取、健康档案、
账单代缴、工具借用、文化服务等专题页，各自有专属交互，且均遵守「社区只做信息与登记、
不撮合不代收资金」的红线。

## 5 技术架构特点

| 维度 | 做法 | 价值 |
|---|---|---|
| 技术栈 | 原生小程序 + TypeScript + 微信云开发 | 轻量、无跨端包袱、随云弹性 |
| 后端形态 | 8 个云函数，统一 `name='资源'` + `data.action` 调用 | 契约与实现一一对应，好定位 |
| 契约驱动 | `contracts/` 为单一事实源（API/数据模型/任务卡） | 前后端、多角色对齐不漂移 |
| 双通道 | `USE_MOCK` 一键切「本地演示 / 真云」 | 演示不依赖后端，联调不重写 |
| 样式工程 | 设计 token + 图标/布局生成器 | 改原型重跑脚本，杜绝手改生成物 |
| 版本守卫 | `version.test.ts` 全仓版本号强一致 | 改版本漏一处即测试失败 |
| 云函数打包 | 共享模块平铺进各函数 | 规避 `MODULE_NOT_FOUND` 经典坑 |
| 安全合规 | 密钥只进环境变量、手机号 AES 加密、隐私声明 | 过审与数据安全有底 |

---

## 6 差异化亮点总结

1. **高密度服务聚合**：38 项高频刚需 + 统一预约，不做单点花哨、做全做稳；
2. **AI 降低门槛**：RAG 问答 + 场景直达 + 安全护栏，让不会打字的老人也能用；
3. **老人友好**：关怀模式全局大字、一键拨号、明码标价、少层级；
4. **工程规范度极高**：契约驱动、版本守卫、生成器、340 条测试，是可长期维护的作品而非一次性 Demo。
