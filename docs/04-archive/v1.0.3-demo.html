三步看懂这版 重点

1. 首页说一句话
点紫色输入框，输入或点预设：我家厨房水管漏水了 → AI 管家自动拆成 4 步。

2. 只补一项
AI 只问「哪一栋」，点一下就好；不会让你重填类别、时间。

3. 确认才提交
草稿卡可改字段，点【确认提交】才真写；成功给工单号 → 看进度时间轴。

其他可点的 已实现

  • 办事页搜索 药品 漏水（别名 + 配图）
  • 报修记录筛选、详情
  • 社区动态 → 通知列表
  • 关怀模式：字号放大 + 宫格 1 列

政务 App 借鉴了什么 原型

  • 一件事一次办：新生儿 / 退休 / 租房备案，把 3~5 个事项打包
  • 预约取号：选业务 → 选时段 → 取号 → 排队进度
  • 证照包：居住证明 / 疫苗档案 / 健康档案（脱敏 + 亮证）
  • 办事进度：统一时间轴
  • 政策计算器：条件问答 → 能不能领 → 材料清单

必须说清楚的两句 仅演示

1. 证照亮证：真实上线需实名与授权，这里是脱敏示意，答辩别说"已对接电子证照"。

2. 政策结论：AI 只做条件初筛，最终以社区审核为准；页面已带免责文案。
