三步看懂这版 重点

1. 首页四个分类
点「生活基础服务 / 健康养老服务 / 便民配套服务 / 文化便民服务」任一卡 → 进分类详情，里面有子板块切换。

2. 点具体服务
保洁、助餐、助浴、适老化改造、生鲜……点任一格 → 进预约登记：只选时间和楼栋，不填表。

3. 缴费 / 工具 / 租售
缴费代办点「户号绑定」看绑定与进度；便民工具点「扫码借用」看借用与到期提醒；房屋租售看房源与业主发布。

政务 App 借鉴了什么 原型

  • 一件事一次办：新生儿 / 退休 / 租房备案，把 3~5 个事项打包
  • 预约取号：选业务 → 选时段 → 取号 → 排队进度
  • 证照包：居住证明 / 疫苗档案 / 健康档案（脱敏 + 亮证）
  • 办事进度：统一时间轴
  • 政策计算器：条件问答 → 能不能领 → 材料清单

必须说清楚的三句 仅演示

1. 没有交易：生鲜、租售、共享设备都只做入口 + 登记，没有购物车、没有支付。个人主体小程序也做不了电商类目。

2. 证照亮证：真实上线需实名与授权，这里是脱敏示意，答辩别说"已对接电子证照"。

3. 政策结论：AI 只做条件初筛，最终以社区审核为准；页面已带免责文案。
