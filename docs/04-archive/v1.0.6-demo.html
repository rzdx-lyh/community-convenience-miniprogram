这一版改了什么 对比 v1.0.4

  • 视觉：绿白圆角 → 政务蓝 + 红竖条分区 + 4 列密集宫格
  • 结构：办事页把 4 个分类做成一级 tab，板块全部平铺，12 项一屏扫完
  • 不再是空壳：每类服务独立流程（见下）

7 条独立流程 重点

  • 缴费代办：3 张账单（欠费金额）+ 户号 + 代办进度
  • 生鲜零售：6 个 SKU + 加减数量 + 底部结算条（只预订不支付）
  • 便民工具：点位图 + 借用中倒计时 + 归还
  • 房屋租售：筛选 + 房源卡 + 我要发布
  • 社区门诊挂号：科室 → 医生 → 时段 → 取号
  • 健康档案：档案卡 + 4 次测量记录 + 签约医生
  • 家政/助餐/助浴/改造：各自不同的服务选项，不是同一个表单

怎么看全 37 项

底部点「办事」→ 顶部 4 个一级 tab（生活/健康/便民/文化）→ 每个板块一张白卡，4 列宫格铺开，不用再点二级。
