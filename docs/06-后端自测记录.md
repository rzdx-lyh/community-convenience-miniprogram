## 5. 已知限制与降级点（评审演示注意事项）

1. **未接真云环境**：全部结论来自本地 mock。真环境需补 3 件事——建 8 个集合 + 建索引（`users.accountId` **唯一索引**、`circle_post.status+publishAt`、`service_category.key` 唯一）、导入 `scripts/seed-data.json`、配环境变量 `TCB_ENV` / `DEEPSEEK_API_KEY` / `PHONE_AES_KEY` / `SUBSCRIBE_TEMPLATE_WORKORDER_DONE`。
2. **AI 未实调**：无 Key，演示时若未配置，`qa:ask` 一律 `degraded=true`（回知识库原文）。配了 Key 才有真实模型生成；答辩建议现场演示"无 Key 也不翻车"。
3. **手机号加密**：未配 `PHONE_AES_KEY` 时使用本地开发密钥并告警，**真环境必须配置**，否则等同明文。
4. **限流是单实例内存计数**：云函数多实例下不严格，仅防误触刷量。
5. **知识库 12 条**（`shared/kb/kb.json`），覆盖报修/水电燃气/医疗医保/疫苗/体检/养老陪护/适老化改造/居住证/社区活动/垃圾分类；关键词 + 同义词打分，未命中阈值 1.0 不调模型。
6. **演示前必做**：10-23 重跑 `node scripts/seed.mjs`，确认紧急通知仍在有效期、圈子页非空（脚本末尾会打印"当前有效 N 条"自检）。
